```java
import org.apache.juneau.http.*;
import org.apache.juneau.rest.server.*;
import org.apache.juneau.rest.server.servlet.*;

@Rest(path="/pets")
public class PetStore extends BasicRestServlet {

    @RestGet("/{id}")
    public Pet get(@Path("id") long id) {
        return store.getPet(id);
    }
}
```

- Content negotiation across every Juneau format, from the request's `Accept` and `Content-Type` headers.
- Generated OpenAPI and Swagger documentation for every resource.
- Runs on Jetty, Tomcat or Spring Boot, or as a config-driven microservice.
- Auth modules for JWT, OAuth, OIDC and SAML.
- Metrics and tracing through Micrometer and OpenTelemetry.
- Serverless tests with `juneau-rest-mock`.
