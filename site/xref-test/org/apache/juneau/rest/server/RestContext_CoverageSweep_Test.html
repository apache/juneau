455 	// NOTE: the "debugDefaultStr non-blank" branch (populated from a `@Rest(debugDefault=...)` annotation
456 	// attribute per the surrounding javadoc) is NOT reasonably testable: `Rest.java` has no `debugDefault()`
457 	// annotation attribute at all (confirmed via a compile error when attempting `@Rest(debugDefault = "ALWAYS")`
458 	// above), so `ai.getString("debugDefault")` can never resolve a value from the annotation chain -- the
459 	// only living contributor is `RestContextProperties.getDebugDefault()` (an env/config-bound property), which
460 	// would require injecting a `PropertySource` bean or mutating a global system property to exercise, both of
461 	// which risk polluting other tests running in the same JVM. Left uncovered; flagged as a likely doc/code
462 	// mismatch (stale `@Rest(debugDefault)` javadoc referencing a removed or never-implemented attribute).
463 	//-----------------------------------------------------------------------------------------------------------
