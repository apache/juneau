236 		// Post-loop "if (state == S2) throw ..." in readIntoBeanMap.  A lone/trailing raw '\' is not
237 		// swallowed by readAttrName once separated from the attribute name (e.g. by whitespace), so it
238 		// is seen directly by the S2 dispatch, matches neither '=' nor '&' nor EOF, and falls through
239 		// leaving state==S2 while isInEscape flips true; the following EOF read then skips S2's own

243 			() -> P.read("\\", Bean1.class));
