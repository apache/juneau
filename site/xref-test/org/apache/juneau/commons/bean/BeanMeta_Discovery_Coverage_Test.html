32  /**
33   * Coverage tests for {@link BeanMeta} paths that are unreachable via the commons-only {@link BeanMeta#of(Class)}
34   * entry point used by {@code BeanMeta_Coverage_Test}:
35   *
36   * <ul>
37   * 	<li>The marshalling-side {@link BeanMeta#create(BeanInfo, ClassInfo)} factory's sanity-check guards
38   * 		(not-a-bean predicates, serializable requirement, {@code @BeanIgnore}, visibility) and its
39   * 		{@code catch (RuntimeException)} fallback — none of these run on the {@link BeanMeta#of} path.
40   * 	<li>{@link BeanFilter}-driven construction (fixed/excluded/read-only/write-only property lists, fluent
41   * 		setters, stop/interface class, property namer overrides) — {@code of()} never builds a
42   * 		{@link BeanFilter} ({@link BeanMetaInitializer#NOOP} always returns <jk>null</jk>), so these branches
43   * 		need a fake {@link BeanMetaInitializer} that supplies one (see {@link BeanTestFakes#initializerWithFilter}).
44   * 	<li>A non-<jk>null</jk> {@code marshallingContext} (per-property {@code BeanRegistry} construction, the
45   * 		bean-level "_type" registry mapping, and the {@link BeanPropertyPostProcessor} hook) — {@code of()}
46   * 		always leaves it <jk>null</jk>.
47   * 	<li>{@code newBean}'s {@code @BeanType(factory=...)} path, non-static-inner-class instantiation, and the
48   * 		{@link org.apache.juneau.commons.inject.BeanStore}-backed factory lookup.
49   * 	<li>A few method/field-discovery edge cases in {@code findBeanMethods}/{@code findBeanFields} (dyna methods,
50   * 		{@code java.beans.Transient}-annotated accessors, non-public record canonical constructors).
51   * </ul>
52   */
