31  /**
32   * Serializes POJO models to the Protocol Buffers <b>binary</b> wire format.
33   *
34   * <h5 class='section'>Media types:</h5>
35   *
36   * Handles <c>Accept</c> types:  <bc>application/protobuf</bc>
37   * <p>
38   * Produces <c>Content-Type</c> types: <bc>application/protobuf</bc>
39   *
40   * <h5 class='topic'>Description</h5>
41   * <p>
42   * Unlike the text-format {@link org.apache.juneau.marshall.prototext.PrototextSerializer} (<c>text/protobuf</c>), this
43   * serializer emits the compact, non-self-describing protobuf binary wire format.  Because the wire carries neither
44   * field names nor specific scalar types, a per-bean field-number/scalar-type table (cached on
45   * {@link ProtobufClassMeta}) is consulted during serialization.  The codec is lossless for Juneau&hArr;Juneau
46   * round-trips, and upgrades field-by-field to external <c>protoc</c> interop via {@link Protobuf @Protobuf}.
47   *
48   * <h5 class='section'>Supported types / scalar mapping:</h5>
49   * <ul class='spaced-list'>
50   * 	<li>{@code boolean}/{@code Boolean} &rarr; bool (varint)
51   * 	<li>{@code byte}/{@code short}/{@code int}/{@code Integer} &rarr; int32 (varint)
52   * 	<li>{@code long}/{@code Long} &rarr; int64 (varint)
53   * 	<li>{@code float}/{@code Float} &rarr; float (I32); {@code double}/{@code Double} &rarr; double (I64)
54   * 	<li>{@link String} &rarr; string; {@code byte[]} &rarr; bytes (length-delimited)
55   * 	<li>{@link Enum} &rarr; int32 ordinal (varint) by default; {@code name()} via {@link Protobuf#type()}={@link ProtobufScalarType#ENUM_STRING}
56   * 	<li>{@link BigInteger}/{@link BigDecimal}/{@code char} and date/time types &rarr; lossless string forms
57   * 	<li>Nested bean &rarr; embedded message; {@link Map} &rarr; repeated <c>entry{key=1,value=2}</c>
58   * 	<li>Repeated scalars &rarr; packed; repeated string/bytes/message &rarr; tagged entries
59   * </ul>
60   *
61   * <h5 class='section'>Field-number assignment:</h5>
62   * <ul class='spaced-list'>
63   * 	<li>Explicit {@link Protobuf#fieldNumber()} overrides are reserved first.
64   * 	<li>Remaining properties are auto-numbered from 1 by alphabetical property name, skipping the reserved 19000&ndash;19999 band.
65   * </ul>
66   *
67   * <h5 class='section'>Limitations / round-trip guarantees:</h5>
68   * <ul class='spaced-list'>
69   * 	<li>Lossless for nullable Juneau&hArr;Juneau round-trips.
70   * 	<li>proto3-inherent:  a primitive set to its zero value is wire-indistinguishable from unset.
71   * 	<li>Unknown fields are skipped (by wire type) but not preserved.
72   * 	<li><c>oneof</c>, full proto2 presence, unknown-field preservation, and well-known types are not supported.
73   * </ul>
74   *
75   * <h5 class='section'>Example:</h5>
76   * <p class='bjava'>
77   * 	<jc>// Serialize a bean to protobuf binary bytes using the default serializer</jc>
78   * 	<jk>byte</jk>[] <jv>bytes</jv> = ProtobufSerializer.<jsf>DEFAULT</jsf>.write(<jv>myBean</jv>);
79   * </p>
80   *
81   * <h5 class='section'>Notes:</h5><ul>
82   * 	<li class='note'>This class is thread safe and reusable.
83   * </ul>
84   *
85   * <h5 class='section'>See Also:</h5><ul>
86   * 	<li class='link'><a class="doclink" href="https://juneau.apache.org/docs/topics/Protobuf">Protobuf Binary Format Basics</a>
87   * 	<li class='link'><a class="doclink" href="https://protobuf.dev/programming-guides/encoding/">Protocol Buffers Encoding</a>
88   * </ul>
89   */
