32  /**
33   * Mixin that serves a request-echo / round-trip introspection endpoint at {@code /echo/*}
34   * (configurable).
35   *
36   * <p>
37   * Sibling of {@link AdminMixin} ({@code /admin/*}) and {@link RouteIndexMixin}
38   * ({@code /options}). All three classes live in the
39   * {@code org.apache.juneau.rest.server.ops} ops/introspection mixin pack.
40   *
41   * <p>
42   * Compose into a host resource via
43   * {@link Rest#mixins() @Rest(mixins=EchoMixin.class)}; the {@code /echo/*} URL becomes
44   * available alongside the host's own endpoints with no further wiring.
45   *
46   * <h5 class='section'>Configurable mount path:</h5>
47   *
48   * <p>
49   * The default mount {@code /echo/*} can be overridden via the SVL variable
50   * {@code ${juneau.echo.path:echo}} &mdash; set via system property
51   * ({@code -Djuneau.echo.path=introspect}), environment variable
52   * ({@code JUNEAU_ECHO_PATH=introspect}), or {@code Config} key
53   * ({@code juneau.echo.path = introspect}) to change the runtime mount without subclassing.
54   * Resolution happens once at {@link RestContext} construction time (SVL resolution in {@code @RestOp(path)}).
55   *
56   * <p>
57   * Override accepts bare token ({@code echo}), leading slash ({@code /echo}), trailing slash
58   * ({@code echo/}), or wildcard suffix ({@code /echo/*}) &mdash; all resolve to the same mount.
59   *
60   * <p>
61   * <b>Migration note (10.0.0):</b> Earlier development snapshots of this mixin mounted at both
62   * {@code /echo/*} <i>and</i> {@code /debug/echo/*} as historical aliases on a single op. That
63   * dual default has been collapsed to a single SVL-configurable mount as part of the
64   * "single path per op" principle. Deployers who relied on the
65   * {@code /debug/echo/*} alias must now either set {@code -Djuneau.echo.path=debug/echo} or
66   * compose a second instance with the override.
67   *
68   * <h5 class='section'>Mixin-only deployment:</h5>
69   *
70   * <p>
71   * This resource is designed for composition via {@code @Rest(mixins=...)}. The mount path is
72   * pinned at the op level by {@link RestOp @RestOp(path="/&#123;juneau.echo.path:echo&#125;/*")} on
73   * {@link #echo}; a class-level {@code @Rest(paths=...)} declaration would be silently ignored
74   * under the mixin pattern (see {@link Rest#paths() @Rest(paths)} Javadoc).
75   *
76   * <h5 class='figure'>Composition example:</h5>
77   *
78   * <p class='bjava'>
79   * 	<ja>@Rest</ja>(
80   * 		path=<js>"/api"</js>,
81   * 		mixins=EchoMixin.<jk>class</jk>
82   * 	)
83   * 	<jk>public class</jk> ApiResource <jk>extends</jk> RestServlet { }
84   *
85   * 	<jc>// Enable the endpoint (default OFF) and, optionally, tighten the body cap or adjust</jc>
86   * 	<jc>// redacted headers via a @Bean factory:</jc>
87   * 	<ja>@Bean</ja> EchoMixin echo() {
88   * 		<jk>return</jk> EchoMixin.<jsm>create</jsm>()
89   * 			.enabled()
90   * 			.bodyLimit(64 * 1024L)
91   * 			.redactHeader(<js>"X-Internal-Trace"</js>)
92   * 			.build();
93   * 	}
94   * </p>
95   *
96   * <h5 class='section'>Enablement:</h5>
97   *
98   * <p>
99   * The endpoint is <b>disabled by default</b>. Reachability is controlled by an explicit, non-logging switch and is
100  * <b>independent of the JUL logger level</b> &mdash; raising a resource's (or operation's) logger to
101  * {@link java.util.logging.Level#FINE FINE}/{@link java.util.logging.Level#FINEST FINEST} never exposes {@code /echo/*}.
102  * When the endpoint is disabled the handler returns {@code 404 Not Found} (so the existence of the endpoint isn't
103  * disclosed).
104  *
105  * <p>
106  * Enablement is tri-state, resolved per request:
107  * <ul class='spaced-list'>
108  * 	<li>An explicit {@link Builder#enabled(Boolean) builder value} ({@code true}/{@code false}) always wins.
109  * 	<li>When the builder value is left unset ({@code null}, the default), the handler resolves the SVL expression
110  * 		{@code ${juneau.echo.enabled:false}} through {@link RestRequest#getVarResolverSession()} &mdash; i.e. the
111  * 		system property {@code -Djuneau.echo.enabled=true} or the relaxed environment variable
112  * 		{@code JUNEAU_ECHO_ENABLED=true}. A per-resource {@code Config} key is <b>not</b> consulted for this switch.
113  * </ul>
114  *
115  * <p>
116  * <b>GLOBAL blast-radius warning:</b> {@code juneau.echo.enabled=true} is a <b>process-wide</b> system-property /
117  * environment switch. It enables {@code /echo/*} on <b>every</b> host in the JVM that mixes in {@code EchoMixin}
118  * &mdash; including hosts the operator did not intend to open &mdash; and, because it is resolved per request, setting
119  * it flips this <b>security</b> switch mid-process without a restart. It is a convenience for single-app deployments
120  * and local testing, <b>not</b> the recommended production posture.
121  *
122  * <p>
123  * <b>Recommended production posture:</b> leave echo OFF by default and enable it per host explicitly via a
124  * {@code @Bean EchoMixin} factory that calls {@link Builder#enabled()}, gated behind an authorization guard chain.
125  * Host-level {@link Rest#guards() @Rest(guards=...)} inherit onto the mixed-in {@code /echo/*} operation, so declaring
126  * guards at the host authorizes the endpoint.
127  *
128  * <h5 class='section'>Sensitive-header redaction:</h5>
129  *
130  * <p>
131  * Token-bearing headers must never be reflected back to the caller (would defeat any auth scheme
132  * in front of the endpoint). The default redacted list is &mdash; case-insensitively &mdash;
133  * {@code Authorization}, {@code Cookie}, {@code Set-Cookie}, {@code Proxy-Authorization}, and
134  * {@code X-API-Key}. Each redacted header surfaces in the echo body with the literal value
135  * {@value #REDACTED} so the caller can see the header was present without leaking its value.
136  * Override the default list via {@link Builder#redactedHeaders(String...)} (replaces) or extend
137  * via {@link Builder#redactHeader(String)} (additive).
138  *
139  * <p>
140  * {@link #REDACTED} and {@link #DEFAULT_REDACTED_HEADERS} are re-exports of
141  * {@link RedactedHeaders#REDACTED} and {@link RedactedHeaders#DEFAULT} respectively; masking is
142  * performed by delegating to {@link RedactedHeaders#redact(String, String, java.util.Collection)}.
143  *
144  * <h5 class='section'>Body capture and truncation:</h5>
145  *
146  * <p>
147  * The handler reads up to {@link Builder#bodyLimit(long) bodyLimit} bytes (default
148  * {@value #DEFAULT_BODY_LIMIT_DOC} = 1 MB) of the inbound body and emits it as a UTF-8 string in
149  * the {@code content} field of the JSON response. When the body exceeds the cap, the captured
150  * portion is truncated and the {@code truncated} flag is set to {@code true} so callers can see
151  * the response is incomplete.
152  *
153  * <h5 class='section'>Response shape:</h5>
154  *
155  * <p class='bjson'>
156  * 	{
157  * 		<jok>"method"</jok>: <jov>"POST"</jov>,
158  * 		<jok>"path"</jok>: <jov>"/echo/foo/bar"</jov>,
159  * 		<jok>"queryString"</jok>: <jov>"x=1"</jov>,
160  * 		<jok>"pathRemainder"</jok>: <jov>"foo/bar"</jov>,
161  * 		<jok>"headers"</jok>: { <jok>"User-Agent"</jok>: <jov>"curl"</jov>, <jok>"Authorization"</jok>: <jov>"[REDACTED]"</jov> },
162  * 		<jok>"queryParams"</jok>: { <jok>"x"</jok>: <jov>"1"</jov> },
163  * 		<jok>"attributes"</jok>: { },
164  * 		<jok>"contentLength"</jok>: <jov>5</jov>,
165  * 		<jok>"content"</jok>: <jov>"hello"</jov>,
166  * 		<jok>"truncated"</jok>: <jov>false</jov>
167  * 	}
168  * </p>
169  *
170  * <p>
171  * The endpoint is excluded from generated Swagger / OpenAPI specs via
172  * {@link OpSwagger#ignore() @OpSwagger(ignore=true)}.
173  *
174  * <h5 class='section'>See Also:</h5><ul>
175  * 	<li class='jc'>{@link AdminMixin}
176  * 	<li class='jc'>{@link RouteIndexMixin}
177  * 	<li class='link'><a class="doclink" href="https://juneau.apache.org/docs/topics/RestServerComposition">REST Server &mdash; Composition (mixins, paths)</a>
178  * </ul>
179  *
180  * @since 10.0.0
181  */

218 	 * Builder constructor.

222 	protected EchoMixin(Builder builder) {
223 		bodyLimit = builder.bodyLimit;
224 		redactedHeaders = u(new LinkedHashSet<>(builder.redactedHeaders));
225 		var s = builder.redactedHeaders.stream().map(h -> h.toLowerCase(Locale.ROOT)).collect(Collectors.toCollection(LinkedHashSet::new));

230 	/**
231 	 * [* /echo/*] &mdash; emit an introspection echo of the inbound request.
232 	 *
233 	 * <p>
234 	 * Returns {@code 404 Not Found} when the endpoint is not {@link Builder#enabled(Boolean) enabled} for the current
235 	 * request. Reachability is independent of the JUL logger level (see the class-level Javadoc for the enablement
236 	 * rules and the global-fallback blast-radius warning).
237 	 *
238 	 * @param req The current REST request.
239 	 * @param res The current REST response.
240 	 * @param remainder The path remainder after the mount prefix (multi-segment, may be empty).
241 	 * @throws IOException If an I/O error occurs while reading the request or writing the response.
242 	 * @throws NotFound When the endpoint resolves to disabled for the current request.
243 	 */
244 	@RestOp(
245 		method="*",
246 		path="/#{pathToken(${juneau.echo.path:echo})}/*",
247 		summary="Request echo",
248 		description="Round-trip introspection of the inbound request. Disabled by default; enable via EchoMixin enablement.",
249 		swagger=@OpSwagger(ignore=true)
250 	)
251 	@SuppressWarnings({
252 		"resource" // sreq.getInputStream() is the servlet container's request body stream; it must not be closed by application code (lifecycle is tied to the request, not this handler).
253 	})
254 	public void echo(RestRequest req, RestResponse res, @Path("/*") String remainder) throws IOException {
255 		var sreq = req.getHttpServletRequest();
256 		var on = enabled != null ? enabled.booleanValue() : Boolean.parseBoolean(req.getVarResolverSession().resolve("${juneau.echo.enabled:false}"));
257 		if (! on)
258 			throw new NotFound("Echo endpoint disabled.");
259 
260 		var headers = new LinkedHashMap<String,String>();
261 		var names = sreq.getHeaderNames();
262 		while (names != null && names.hasMoreElements()) {
263 			var name = names.nextElement();
264 			headers.put(name, RedactedHeaders.redact(name, sreq.getHeader(name), redactedHeaders));
265 		}
266 
267 		var queryParams = new LinkedHashMap<String,String>();
268 		for (var p : req.getQueryParams())
269 			queryParams.put(p.getName(), p.asString().orElse(null));
270 
271 		var attributes = new LinkedHashMap<String,String>();
272 		req.getAttributes().asMap().forEach((k, v) -> attributes.put(k, String.valueOf(v)));
273 
274 		var capture = readBoundedBody(sreq.getInputStream(), bodyLimit);
275 
276 		var out = new LinkedHashMap<String,Object>();
277 		out.put("method", req.getMethod());
278 		out.put("path", sreq.getRequestURI());
279 		out.put("queryString", sreq.getQueryString());
280 		out.put("pathRemainder", remainder == null ? "" : remainder);
281 		out.put("headers", headers);
282 		out.put("queryParams", queryParams);
283 		out.put("attributes", attributes);
284 		out.put("contentLength", capture.bytesRead);
285 		if (capture.bytesRead > 0)
286 			out.put("content", new String(capture.bytes, StandardCharsets.UTF_8));
287 		out.put("truncated", capture.truncated);
288 
289 		try (var w = res.getDirectWriter("application/json")) {
290 			JsonSerializer.DEFAULT_READABLE.write(out, w);
291 		}
292 	}

322 	@SuppressWarnings({
323 		"java:S135" // The two breaks are distinct truncation exits (limit-reached vs. partial-final-chunk); merging them would obscure the bounded-read logic.
324 	})
325 	private static BodyCapture readBoundedBody(InputStream in, long limit) throws IOException {
326 		if (in == null)
327 			return new BodyCapture(new byte[0], 0, false);
328 		var buf = new ByteArrayOutputStream();
329 		var chunk = new byte[8192];
330 		var truncated = false;
331 		long total = 0;
332 		int n;
333 		while ((n = in.read(chunk)) != -1) {
334 			var room = limit - total;
335 			if (room <= 0) {
336 				truncated = true;
337 				break;
338 			}
339 			if (n > room) {
340 				buf.write(chunk, 0, (int) room);
341 				total += room;
342 				truncated = true;
343 				break;
344 			}
345 			buf.write(chunk, 0, n);
346 			total += n;
347 		}
348 		return new BodyCapture(buf.toByteArray(), total, truncated);
349 	}

351 	private static final class BodyCapture {
352 		final byte[] bytes;
353 		final long bytesRead;
354 		final boolean truncated;
355 
356 		BodyCapture(byte[] bytes, long bytesRead, boolean truncated) {
357 			this.bytes = bytes;
358 			this.bytesRead = bytesRead;
359 			this.truncated = truncated;
360 		}

367 
368 		private long bodyLimit = DEFAULT_BODY_LIMIT;
369 		private final Set<String> redactedHeaders;
370 		private Boolean enabled;
371 
372 		/** Constructor &mdash; package access for {@link EchoMixin#create()}. */
373 		protected Builder() {
374 			redactedHeaders = new LinkedHashSet<>(DEFAULT_REDACTED_HEADERS);
375 		}

377 		/**
378 		 * Sets the explicit enablement tri-state for the {@code /echo/*} endpoint.
379 		 *
380 		 * <p>
381 		 * This is a non-logging switch that is independent of the JUL logger level. The default is unset
382 		 * ({@code null}), which defers to the {@code ${juneau.echo.enabled:false}} deployment fallback (system
383 		 * property / relaxed environment variable) &mdash; see the class-level Javadoc for the resolution rules and
384 		 * the global-fallback blast-radius warning.
385 		 *
386 		 * @param value {@code Boolean.TRUE} to enable, {@code Boolean.FALSE} to explicitly disable (overriding the
387 		 * 	global fallback), or {@code null} to leave unset (defer to the fallback).
388 		 * @return This object.
389 		 */
390 		public Builder enabled(Boolean value) {
391 			enabled = value;
392 			return this;
393 		}
394 
395 		/**
396 		 * Enables the {@code /echo/*} endpoint &mdash; shorthand for {@link #enabled(Boolean) enabled(Boolean.TRUE)}.
397 		 *
398 		 * @return This object.
399 		 */
400 		public Builder enabled() {
401 			return enabled(Boolean.TRUE);
402 		}
403 
404 		/**
405 		 * Sets the body capture cap.
406 		 *
407 		 * <p>
408 		 * Captured content is truncated when the inbound body exceeds this size; the
409 		 * {@code truncated} flag in the response is set to {@code true}.
410 		 *
411 		 * @param value Cap, in bytes. Must be {@code >= 0}.
412 		 * @return This object.
413 		 */
414 		public Builder bodyLimit(long value) {
415 			if (value < 0)
416 				throw new IllegalArgumentException("bodyLimit must be >= 0");
417 			bodyLimit = value;
418 			return this;
419 		}
420 
421 		/**
422 		 * Replaces the redacted-header set with the supplied values.
423 		 *
424 		 * <p>
425 		 * Header names are matched case-insensitively. Pass an empty array to disable redaction
426 		 * (not recommended outside of integration tests).
427 		 *
428 		 * @param values The header names to redact. Can be {@code null} (equivalent to an empty array
429 		 * 	&mdash; disables redaction); {@code null} or blank elements are skipped.
430 		 * @return This object.
431 		 */
432 		public Builder redactedHeaders(String...values) {
433 			redactedHeaders.clear();
434 			if (values != null)
435 				for (var v : values)
436 					if (v != null && ! v.isBlank())
437 						redactedHeaders.add(v);
438 			return this;
439 		}
440 
441 		/**
442 		 * Adds an additional header name to the redacted-header set.
443 		 *
444 		 * @param value The header name to redact (case-insensitive). Must not be {@code null} or
445 		 * 	blank.
446 		 * @return This object.
447 		 */
448 		public Builder redactHeader(String value) {
449 			if (isBlank(value))
450 				throw new IllegalArgumentException("Argument 'value' must not be null or blank");
451 			redactedHeaders.add(value);
452 			return this;
453 		}
