26  /**
27   * A per-row action descriptor in the {@code VIEW_META} wire contract (the transport-agnostic
28   * "row-action intent" model).
29   *
30   * <p>
31   * An FTL {@code <@card type="datatables">} {@code VIEW_META} catalog declares zero or more of these via
32   * {@code rowActions}; the
33   * {@code juneau-views.js} runtime renders each as a row-menu item and, on activation, submits the declared
34   * {@link #endpoint} with the declared {@link #method} as a JSON request carrying the process's CSRF token.
35   *
36   * <h5 class='section'>The frozen wire schema</h5>
37   * <p>
38   * This is the <b>complete</b> set of wire fields; it is pinned in full now so that later waves (a future declarative
39   * modal/form + typed result) can rely on it verbatim without forcing another fail-loud
40   * contract bump.  Only {@link #id} is required; every other field is optional and is omitted from the serialized
41   * form when unset (null-valued properties are dropped).
42   * <table class='styled'>
43   * 	<tr><th>Field</th><th>Type / tokens</th><th>Meaning</th></tr>
44   * 	<tr><td>{@code id}</td><td>string</td><td>Stable action id (menu-item key; also the submit's logical name).</td></tr>
45   * 	<tr><td>{@code label}</td><td>string</td><td>The menu-item text.</td></tr>
46   * 	<tr><td>{@code icon}</td><td>string</td><td>Optional glyph name (resolved by the shared icon registry).</td></tr>
47   * 	<tr><td>{@code endpoint}</td><td>string</td><td>The URL the action submits to; may carry a {@code {property}}
48   * 		token substituted from the current row - a value that cannot be resolved refuses the submission (see
49   * 		{@link #endpoint(String) endpoint}).</td></tr>
50   * 	<tr><td>{@code method}</td><td>{@code POST}|{@code PUT}|{@code PATCH}|{@code DELETE}</td>
51   * 		<td>The non-safe HTTP method (see {@link Method}).</td></tr>
52   * 	<tr><td>{@code confirm}</td><td>string</td><td>Optional confirmation prompt shown before the submit.</td></tr>
53   * 	<tr><td>{@code form}</td><td>string</td><td>Optional form-source URL supplying the action's input fields;
54   * 		may carry a {@code {property}} token substituted from the current row before the confirmation GET
55   * 		(see {@link #form(String) form}).  Blank/absent {@code form} is the confirm-only local path.</td></tr>
56   * 	<tr><td>{@code present}</td><td>{@code page}|{@code dialog}|{@code inline}</td>
57   * 		<td>How the action's form/confirmation is presented (see {@link Present}); {@code inline} keeps it out of the row menu.</td></tr>
58   * 	<tr><td>{@code onSuccess}</td><td>{@code redraw}|{@code mergeRow}|{@code navigate}</td>
59   * 		<td>What the runtime does with a successful result (see {@link OnSuccess}).</td></tr>
60   * 	<tr><td>{@code enabledWhen}</td><td>{@code [{field,op,value?,reason}, ...]}</td>
61   * 		<td>Row-state disable-with-reason rules (see {@link #enabledWhen(String,Op,Object,String)}).</td></tr>
62   * 	<tr><td>{@code visibleWhen}</td><td>{@code [{field,op,value?}, ...]}</td>
63   * 		<td>Row-state visibility rules (see {@link #visibleWhen(VisibilityRule...)}).</td></tr>
64   * 	<tr><td>{@code tone}</td><td>{@code default}|{@code danger}</td>
65   * 		<td>Styling of the confirmation (see {@link Tone}); {@code danger} focuses Cancel first.</td></tr>
66   * 	<tr><td>{@code confirmLabel}</td><td>string</td>
67   * 		<td>Text of the confirm button; defaults to the action's {@code label}.</td></tr>
68   * 	<tr><td>{@code confirmRenderer}</td><td>string</td>
69   * 		<td>Name of a confirm renderer registered with the client runtime; absent means the built-in modal.
70   * 		Like {@code confirm}, it is not consulted when an inline cell edit commits (that never prompts).</td></tr>
71   * </table>
72   *
73   * <p>
74   * {@code enabledWhen} was added after this schema was first frozen; like {@code ModalDef#barSlot}, it is
75   * additive-only (<jk>null</jk> when unset, omitted from the serialized form) and its presence does not bump
76   * {@code VIEW_META} &mdash; a {@link RowAction} that leaves it unset serializes
77   * unchanged, and old {@code juneau-views.js} ignores the unknown key.
78   *
79   * <h5 class='section'>Why {@link #method} cannot be a safe method</h5>
80   * <p>
81   * {@link Method} enumerates only {@code POST}/{@code PUT}/{@code PATCH}/{@code DELETE}, so a safe (CSRF-exempt)
82   * method cannot be declared at all &mdash; a build-time refusal by construction.  This mirrors the server boundary:
83   * {@link org.apache.juneau.rest.server.MethodSafety} fails any {@code @Mutating} operation bound to a safe method at
84   * startup, and {@link org.apache.juneau.rest.server.filter.LoopbackBoundary} applies its Origin/CSRF/JSON checks
85   * only to non-safe methods.  A mutating action bound to {@code GET} would be a CSRF-able write; the type system
86   * forbids expressing one.
87   *
88   * <h5 class='section'>Per-row {@code {property}} substitution in {@link #endpoint} and {@link #form}</h5>
89   * <p>
90   * {@link #endpoint(String) endpoint} and {@link #form(String) form} may each carry a {@code {property}} token
91   * (e.g. {@code {id}}, as in the example below) that the client-side runtime substitutes from the row &mdash; the
92   * SAME mechanism, same token grammar, and same per-value escaping as the {@code linked} cell renderer's
93   * {@code href} interpolation.  Unlike a rendered {@code href}, these URLs are <i>fetched</i> (form: confirmation GET) or
94   * <i>submitted</i> (endpoint: mutating write), so an unresolved substitution <b>refuses</b> instead of issuing a
95   * malformed request; see each setter's javadoc for the full contract.  A value with no token is unaffected and
96   * is used as declared.  A blank/absent {@code form} is the confirm-only local path (no
97   * GET), not a refusal.
98   *
99   * <h5 class='section'>Example:</h5>
100  * <p class='bjava'>
101  * 	RowAction <jv>delete</jv> = RowAction.<jsm>create</jsm>(<js>"delete"</js>)
102  * 		.label(<js>"Delete"</js>)
103  * 		.endpoint(<js>"servlet:/incidents/{id}"</js>)
104  * 		.method(RowAction.Method.<jsf>DELETE</jsf>)
105  * 		.confirm(<js>"Delete incident {id}?"</js>)
106  * 		.confirmLabel(<js>"Delete forever"</js>)
107  * 		.tone(RowAction.Tone.<jsf>DANGER</jsf>)
108  * 		.visibleWhen(VisibilityRule.<jsm>when</jsm>(<js>"locked"</js>).ne(<jk>true</jk>));
109  * </p>
110  *
111  * <h5 class='section'>See Also:</h5>
112  * <ul>
113  * 	<li class='jc'>{@link Render}
114  * </ul>
115  *
116  * @since 10.0.0
117  */

396 	/**
397 	 * Sets the URL this action submits to.
398 	 *
399 	 * <p>
400 	 * May contain one or more {@code {property}} tokens (e.g. {@code "servlet:/incidents/{id}/ack"}), substituted
401 	 * from the CURRENT ROW's own already-fetched data at submit time &mdash; the client-side ({@code
402 	 * juneau-views.js}) runtime, not this Java layer, performs the substitution, by delegating to the identical
403 	 * {@code interpolateHref} helper the {@code linked} cell renderer uses
404 	 * (juneau-renders.js): the SAME token grammar (any {@code {property}}, not a hardcoded {@code {id}}) and the
405 	 * SAME per-value {@code encodeURIComponent} escaping &mdash; unchanged.
406 	 *
407 	 * <p>
408 	 * <b>Divergence from a rendered {@code href} is deliberate:</b> because this URL is <i>submitted</i>
409 	 * rather than merely rendered, the runtime <b>refuses the submission</b> (renders a visible refusal; issues no
410 	 * request; never a request-time exception) instead of firing a malformed or undeclared write, when:
411 	 * <ul>
412 	 * 	<li>a {@code {property}} token's row value is absent, <jk>null</jk>, or blank;
413 	 * 	<li>the resolved URL still carries an unsubstituted {@code {property}} token (e.g. the page shipped
414 	 * 		{@code juneau-views.js} without its {@code juneau-renders.js} peer);
415 	 * 	<li>the resolved URL contains a {@code ..} path segment (which browser URL resolution would otherwise
416 	 * 		normalize into a different, undeclared endpoint); or
417 	 * 	<li>no {@code endpoint} is declared at all.
418 	 * </ul>
419 	 * {@code Column.href} keeps substituting to an empty string in each of these cases, because a rendered link is
420 	 * not a write.
421 	 *
422 	 * <p>
423 	 * <b>Backward compatible, narrowed:</b> an {@code endpoint} with no {@code {...}} token is still
424 	 * issued as declared (three of the four guards above cannot fire on it; the fourth,
425 	 * the {@code ..} check, only fires on an author-declared {@code ..}).  An {@code endpoint} WITH a token now
426 	 * refuses in cases that previously submitted a malformed URL (e.g. {@code "servlet:/incidents//ack"} for a
427 	 * row with no {@code id}) rather than issuing it.
428 	 *
429 	 * @param value The new value.
430 	 * @return This object.
431 	 */
432 	public RowAction endpoint(String value) {
433 		endpoint = value;
434 		return this;
435 	}

536 	 * confirm-only local path (no GET), not a {@code no-endpoint} refusal.  A token-less {@code form} is fetched

570 	 * Gates this action on the row's own state, comparing one field against one value.
571 	 *
572 	 * <p>
573 	 * Mirrors {@code ActionRef.enabledWhen(String,Op,Object,String)} on the detail-panel {@code ActionBar}

581 	 * @param op The comparison operator.  Must be {@link Op#EQ} or {@link Op#NE}.

583 	 * @param reason Why the action is unavailable when this rule does not match.  Must not be <jk>null</jk> or
584 	 * 	blank.
585 	 * @return This object.
586 	 */
587 	public RowAction enabledWhen(String field, Op op, Object value, String reason) {
