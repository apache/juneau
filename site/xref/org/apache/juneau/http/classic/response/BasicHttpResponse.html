36  /**
37   * Basic implementation of the {@link HttpResponse} interface.
38   *
39   * <p>
40   * Although this class implements the various setters defined on the {@link HttpResponse} interface, it's in general
41   * going to be more efficient to set the status/headers/content of this bean through the builder.
42   *
43   * <p>
44   * Immutability is expressed with the "funnel + nested {@code Unmodifiable} snapshot" paradigm: every mutator (fluent
45   * setter and {@code void} interface mutator) routes through the single protected {@link #modify(Runnable)} choke-point,
46   * and each concrete leaf gets a nested {@code X.Unmodifiable} whose only behavioral override is a throwing
47   * {@code modify(...)}.  A leaf's {@link #unmodifiable()} factory returns a point-in-time snapshot of type
48   * {@code X.Unmodifiable}; any attempt to set a property on it throws an {@link UnsupportedOperationException}.
49   *
50   * <p>
51   * This is a self-typed (CRTP) root: a leaf declares <c>class Ok <jk>extends</jk> BasicHttpResponse&lt;Ok&gt;</c> and
52   * inherits leaf-typed fluent setters with no covariant overrides.
53   *
54   * <h5 class='section'>Notes:</h5><ul>
55   * 	<li class='warn'>Beans are not thread safe unless they're marked as unmodifiable.
56   * </ul>
57   *
58   * <h5 class='section'>See Also:</h5><ul>
59   * 	<li class='link'><a class="doclink" href="https://juneau.apache.org/docs/topics/JuneauRestCommon">juneau-rest-common Basics</a>
60   * </ul>
61   *
62   * @param <SELF> The self type for fluent setters.
63   */
64  @Marshalled(as=MarshalledAs.STRING)
65  @SuppressWarnings({
66  	"java:S115", // Constants use UPPER_snakeCase convention (e.g., PROP_status)
67  	"java:S119" // 'SELF' (CRTP self-type) is intentional and clearer than a single-letter name.
68  })

474 	/**
475 	 * Single mutation funnel — the only choke-point through which all state changes on this bean flow.
476 	 *
477 	 * <p>
478 	 * Every mutator (fluent setter and {@code void} interface mutator) routes through this method.  The nested
479 	 * {@code Unmodifiable} snapshot overrides only this method to throw, which freezes the entire mutation surface with
480 	 * a single override.
481 	 *
482 	 * @param mutation The state change to apply.
483 	 * @return This object.
484 	 */
485 	protected SELF modify(Runnable mutation) {
486 		mutation.run();
487 		return self();
488 	}

490 	/**
491 	 * Deep-freeze hook invoked from the nested {@code Unmodifiable} constructor after the snapshot copy completes.
492 	 *
493 	 * <p>
494 	 * The mutable sub-beans are frozen here by <b>direct field assignment</b> (never via a setter, which would route
495 	 * through the throwing {@link #modify(Runnable)} and blow up during construction).  A leaf that adds its own mutable
496 	 * sub-bean overrides this method (calling {@code super.freeze()} first).
497 	 */
498 	protected void freeze() {
499 		statusLine = statusLine.unmodifiable();   // DIRECT field write — must NOT use setStatusLine(...)
500 		headers = headers.unmodifiable();         // DIRECT field write — snapshot the copied HeaderList.
501 	}
