❓ Comma-delimited list of column=expression clauses, ANDed together.

Example:  name=$contains(smith), age=$gte(18)

Bare values (no operator):
- Text columns: case-insensitive substring; '*' = any run, '?' = one character
   e.g. [name=smi*]
- Number/date/boolean columns: typed equals
   e.g. [age=42]

Operators:
$eq(v) - Exact, case-sensitive match
$eqic(v) - Exact, case-insensitive match
$ne(v,...) - None of the given values match
$in(v,...) - Any of the given values match
$contains(v) - Case-insensitive substring (text only)
$prefix(v) - Case-insensitive prefix (text only)
$regex(p[,flags]) - Full-string regex match (text only); quote patterns containing , ( or ), e.g. $regex("a{1,3}")
$blank() - Empty or whitespace-only
$gt(v) / $gte(v) / $lt(v) / $lte(v) - Typed comparison (number/date only)
$between(lo,hi) - Inclusive range (number/date only)

Combining:
$and(a,b,...) / $or(a,b,...) / $not(a) - Logical grouping, nestable
   e.g. [status=$or($eqic(open),$eqic(pending))]
❓ Comma-delimited list of columns to display, in order.

Example:  name, age
❓ Comma-delimited list of columns to sort by.
Append ':desc' (or '-') to a column to sort it descending; the default is ascending.

Example:  name, age:desc
