# Apache Juneau — test performance baselines.

# Read by the perf guard in scripts/test.py (run_perf_guard), which runs after `mvn test` in
# `scripts/test.py --full` and in scripts/push.py.  Warn-only unless --enforce-perf.
#
# FORMAT — one entry per line:   <key> = <seconds>     # optional trailing comment
#
#   suite            The real wall clock of the whole `mvn test -T1C` phase.  Breaches above
#                    suite × (1 + tolerance).
#
#   [modules]        <module path> = <seconds>: a reactor module's wall clock, from the Reactor
#                    Summary Maven prints (path relative to the repo root, e.g.
#                    "juneau-rest/juneau-rest-mock").  A module breaches only when it is over
#                    baseline × (1 + tolerance) AND more than min-seconds over its baseline.  A
#                    module with no entry warns and never fails.
#
#   [observability]  Read by scripts/microbench.py, not by the perf guard.
#
# Tolerance: JUNEAU_CI_PERF_THRESHOLD (default 0.20).  Min seconds: JUNEAU_CI_PERF_MIN_SECONDS (default 3).
#
# To re-baseline once a few test.py runs have recorded module timings:
#     python3 scripts/test.py --rebaseline [--window 20] [--min-runs 5]
# It reads this repo's test.py run history (the passing `tests` records in
# ~/.cache/juneau-run/history/<repo>-<sha8>/test.jsonl, shared by every branch and worktree) that have
# the newest record's command signature (so --no-container and wrapper runs don't skew it), takes
# each key's median over its last 20 passing runs (dropping runs over 3× that median), rounds up to
# 0.1s, rewrites the suite line and the [modules] section, and prints what changed.  A key with
# fewer than 5 runs keeps its value; a command shape with fewer than 5 runs prints "no baseline for this
# command shape" and rewrites nothing.  With JUNEAU_RUN_HISTORY=0 there is no history and nothing is
# rewritten.  Review the diff; nothing is committed.
#
# --rebaseline rewrites the [modules] section wholesale: keep comments above the [modules] line,
# and keep the suite line above it too.
#
# Consumers: scripts/test.py (read_baselines, run_perf_guard, rebaseline) and
#            scripts/microbench.py ([observability]).
# ============================================================================
