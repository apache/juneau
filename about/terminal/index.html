Juneau Terminal

Live terminal boards for builds, tests and scripts.

Get startedDocumentation
python3 juneau_terminal.py --console board maven -- mvn clean install

The board shows one row per step, with its time, a progress bar and test counts, and a line under it for each running Maven module:

  • One live row per stage for Maven, npm, pytest and Playwright.
  • Full logs on disk.
  • A plain-output fallback off a terminal.
  • The Terminal view and Terminal regions in the console.

Modules: juneau-terminal, juneau-terminal-report, juneau-terminal-region, juneau-terminal-bus
