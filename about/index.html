About Apache Juneau™

Apache Juneau™ turns Java objects into JSON, XML, HTML, YAML and many other formats, and parses them back, through one API. REST servers and clients are built on the same model, so the beans you serialize are the beans you serve and call over HTTP.

Looking for...​

Data

  • Juneau Marshall: One bean. Every format.
  • Juneau Beans: Ready-made beans for the specs you already use.
  • Juneau Bean Query: Search, sort, project and page beans with one query, in memory or in a database.

Web

  • Juneau REST Server: Annotate a POJO and serve it as REST in every format Juneau speaks.
  • Juneau REST Client: Call REST APIs through typed Java interfaces.
  • Juneau Console: Browser admin consoles built from your REST resources.
  • Juneau AI: Expose your services to AI agents over MCP.

Foundations

  • Juneau Commons: The reflection, collection and settings utilities Juneau is built on.
  • Juneau Config: Configuration files as POJOs, with variables and live reload.
  • Juneau BCT: Bean-Centric Testing: assert on whole beans in one line.
  • Juneau Terminal: Live terminal boards for builds, tests and scripts.

See it running​

The juneau-petstore sample runs on Jetty and Spring Boot with an admin console that uses the projects above, and juneau-terminal turns Maven, npm and other build output into the Terminal views the console shows.

When to Choose Juneau​

Not sure if Juneau is right for your project? Check out our detailed Why Choose Juneau? page for a comprehensive comparison with alternatives, or see our Framework Comparisons page for detailed technical comparisons.

Quick summary: Choose Juneau when you need multi-format serialization, REST APIs with automatic content negotiation, or want an integrated solution with no required dependencies for marshalling (Framework Comparisons). Also consider it when the same Java service needs a server-rendered admin console (console chrome and rich table views) or an MCP endpoint, without adding a separate front-end stack. Upgrading from 9.x? See the V10.0 Migration Guide.

For every module, including the bean DTOs, shaded jars and bundles, see the Juneau Ecosystem overview.
