About Apache Juneau™

Apache Juneau™ turns Java objects into JSON, XML, HTML, YAML and many other formats, and parses them back, through one API. REST servers and clients are built on the same model, so the beans you serialize are the beans you serve and call over HTTP.

What you can do​

Marshalling​

Serialize and parse Java beans as JSON, XML, HTML, YAML, CSV, MessagePack, RDF and more, with no required dependencies. See juneau-marshall.

REST servers and microservices​

Build self-documenting REST APIs from annotated Java classes with juneau-rest-server, and run them as a microservice on Jetty or Tomcat, or inside Spring Boot.

REST clients​

Call REST APIs with POJO mapping using the REST client or the classic client, and turn a Java interface into type-safe calls with remote proxies.

Testing​

Write compact, bean-aware assertions with juneau-test, and test REST APIs without a servlet container using juneau-rest-mock.

Configuration​

Read INI and YAML configuration files as POJOs, with variable resolution and live file watching, using juneau-config.

Admin consoles and UI​

Build a themeable, server-rendered admin console on juneau-rest-server with the console chrome; Building a Console Page is the end-to-end tutorial. Rich table views give plain beans search, sort, paging and row actions. Pages can draw chart cards, show multi-step runs in the Run View Region (fed by juneau-run) and raw command output in the Terminal Region, and start long-running work from a job-log card, row jobs or async jobs, with live updates over the console message bus. Declarative widgets and Markdown rendering cover forms and text, and template views are available for JSP, Thymeleaf, Mustache and FreeMarker.

AI and MCP​

Expose tools, prompts and resources to AI assistants from a REST resource with juneau-rest-server-mcp, built on the MCP wire beans. Start with the MCP Quickstart, then choose your MCP setup.

See it running​

The juneau-petstore sample runs on Jetty and Spring Boot with an admin console that uses the pieces above, and juneau-run turns Maven, npm and other build output into the run views the console shows.

When to Choose Juneau​

Not sure if Juneau is right for your project? Check out our detailed Why Choose Juneau? page for a comprehensive comparison with alternatives, or see our Framework Comparisons page for detailed technical comparisons.

Quick summary: Choose Juneau when you need multi-format serialization, REST APIs with automatic content negotiation, or want an integrated solution with minimal dependencies. Also consider it when the same Java service needs a server-rendered admin console (console chrome and rich table views) or an MCP endpoint, without adding a separate front-end stack. Upgrading from 9.x? See the V10.0 Migration Guide.

Pick your module​

ModuleUse it for
juneau-marshallSerializers and parsers for JSON, XML, HTML, YAML and more.
juneau-configINI and YAML configuration files as POJOs.
juneau-rest-serverAnnotation-based REST servers with content negotiation and OpenAPI docs.
juneau-rest-clientREST clients with POJO mapping and remote proxies.
juneau-microserviceA runnable REST microservice on Jetty or Tomcat.
juneau-test / juneau-rest-mockBean-aware assertions and serverless REST tests.
juneau-rest-server-console-uiServer-rendered admin console chrome.
juneau-rest-server-mcpMCP servers for AI assistants.

For every module, including the bean DTOs, shaded jars and bundles, see the Juneau Ecosystem overview.
