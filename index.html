One bean. Every format.

Serialize any Java object to JSON, XML, HTML, YAML and more with one API, then serve it over REST.

Get startedDocumentation
record Person(String name, int age) {}
  • JSON
  • XML
  • YAML
  • HTML
Json.of(new Person("Ada", 36))
Output
{"age":36,"name":"Ada"}
Xml.of(new Person("Ada", 36))
Output
<object><age>36</age><name>Ada</name></object>
Yaml.of(new Person("Ada", 36))
Output
age: 36
name: Ada
Html.of(new Person("Ada", 36))
Output
<table><tr><td>age</td><td>36</td></tr><tr><td>name</td><td>Ada</td></tr></table>

The Juneau projects

Data

  • Juneau MarshallOne bean. Every format.
  • Juneau BeansReady-made beans for the specs you already use.
  • Juneau Bean QuerySearch, sort, project and page beans with one query, in memory or in a database.

Web

  • Juneau REST ServerAnnotate a POJO and serve it as REST in every format Juneau speaks.
  • Juneau REST ClientCall REST APIs through typed Java interfaces.
  • Juneau ConsoleBrowser admin consoles built from your REST resources.
  • Juneau AIExpose your services to AI agents over MCP.

Foundations

  • Juneau CommonsThe reflection, collection and settings utilities Juneau is built on.
  • Juneau ConfigConfiguration files as POJOs, with variables and live reload.
  • Juneau BCTBean-Centric Testing: assert on whole beans in one line.
  • Juneau TerminalLive terminal boards for builds, tests and scripts.

See it running

The juneau-petstore sample runs on Jetty and Spring Boot with an admin console that uses the projects above, and juneau-terminal turns Maven, npm and other build output into the Terminal views the console shows.

When to Choose Juneau

Not sure if Juneau is right for your project? Check out our detailed Why Choose Juneau? page for a comprehensive comparison with alternatives, or see our Framework Comparisons page for detailed technical comparisons.

Quick summary: Choose Juneau when you need multi-format serialization, REST APIs with automatic content negotiation, or want an integrated solution with no required dependencies for marshalling (Framework Comparisons). Also consider it when the same Java service needs a server-rendered admin console (console chrome and rich table views) or an MCP endpoint, without adding a separate front-end stack.
