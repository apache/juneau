The console-output region is a live-tailing log pane for views and console pages. It polls a lines endpoint,
appends new lines, keeps itself pinned to the bottom while the user is following, and lets the user load
earlier lines and download the whole log as JSONL. Line data follows the OpenTelemetry log model: a level, an
optional timestamp, and a body of plain text or styled fragments.

You can show one in three ways:

| Where | How |
|---|---|
| A console page card | `<@card type="console-output" id="build-log">{ contractVersion: '1', output: {...} }</@card>` |
| A views page region | `ConsoleOutputDef.forMixin(...).toRegion()` in a `RegionTable` |
| A table row detail | A `datatables` catalog `detail.region` with `populate: 'console-output'` and `params` |

The server half ships in `juneau-rest-server-views` (`org.apache.juneau.rest.server.views`); the client half is
`juneau-console-output.js`, part of the `views` toolkit pack.

## The line contract

Each line is one JSON object. Absent members are omitted, never sent as `null`.

```json5
{
  n: 42,                                   // 1-based, server-assigned, strictly increasing
  instant: "2026-10-07T13:04:05.123Z",     // optional; UTC, millisecond precision
  level: "INFO",                           // SEVERE | WARNING | INFO | FINE; default INFO
  text: "Compiling 214 sources",           // exactly one of text | frags
  ui: { style: "success", icon: "check" }  // optional display hints
}
```

| Field | Rule |
|---|---|
| `n` | Required in a page response. Gaps are allowed; duplicates and decreases are not. |
| `instant` | Optional ISO-8601 with `Z`. |
| `level` | `SEVERE`, `WARNING`, `INFO` or `FINE`. Anything else is rejected. |
| `text` | May contain `\n` (the row wraps; it keeps one line number). Other control characters except tab are replaced with U+FFFD. |
| `frags` | 1 to 512 fragments, instead of `text`. |
| `ui` | Optional display hints, below. |

In Java, build lines with `ConsoleOutputLine`:

```java
ConsoleOutputLine.info("Compiling 214 sources");
ConsoleOutputLine.warning("3 deprecation warnings");
ConsoleOutputLine.info("Tests passed").icon("check").style(Style.SUCCESS);
```

### Levels

| `level` | OTel SeverityNumber | Default style | `java.util.logging` |
|---|---|---|---|
| `SEVERE` | 17 (ERROR) | `error` | `SEVERE` |
| `WARNING` | 13 (WARN) | `warn` | `WARNING` |
| `INFO` | 9 (INFO) | none | `INFO`, `CONFIG` |
| `FINE` | 5 (DEBUG) | `muted` | `FINE`, `FINER`, `FINEST` |

Only `level` is on the wire. `Level.severityNumber()` derives the number.

### Fragments

`frags` replaces `text` when a line needs mixed styling. A fragment is either:

- a **text fragment**, `{text, style?, color?, bold?}`, drawn as a span; or
- a **block fragment**, `{block: true, style?, color?, tooltip?, href?, label?}`, drawn as a small filled box.
  Use blocks for progress strips. A block with an `href` is a link; a block with a `tooltip` is focusable and
  shows the tooltip on hover and focus; `label` is its accessible name (it falls back to `tooltip`).

```java
ConsoleOutputLine.frags(
	Frag.text("Steps "),
	Frag.block().style(Style.SUCCESS).tooltip("Step 1: build\nok").href("#build-L12"),
	Frag.block().style(Style.ERROR).tooltip("Step 2: test\nfailed").href("#build-L40"));
```

Fragments do not nest and do not carry `ui`.

### Display hints (`ui`)

| Member | Rule |
|---|---|
| `style` | `success`, `warn`, `error`, `muted` or `accent`; follows the theme. |
| `color` | `#rgb`, `#rrggbb` or `rgb(r,g,b)` only. Wins over `style`. Prefer `style`: a fixed colour cannot follow the theme. |
| `icon` | A registered icon name, drawn before the text. An unknown name is dropped (E-CO-6). |
| `image` | `{src, alt, width?}`. `src` must be a same-origin path starting with `/`. Drawn below the text. |
| `marker` | `true` marks structural chatter that the user may dim or hide. |

A line's colour is `ui.color`, else `ui.style`, else the level's default style, else the console text colour.
A fragment's colour is `frag.color`, else `frag.style`, else the line's colour.

## The lines endpoint

`GET {linesUrl}` returns one page:

```json5
{
  contractVersion: "1",
  lines: [ { n: 41, text: "…" }, { n: 42, text: "…" } ],
  next: "18342",          // echo back as ?after=
  more: false,            // true: the server capped this page; fetch again now
  hasEarlier: true,       // lines exist before lines[0]
  before: "409.17",       // echo back as ?before= (present when hasEarlier)
  state: "RUNNING",       // display text
  stateStyle: "accent",
  terminal: false,        // true: stop polling
  startedAt: "2026-10-07T13:00:00Z",
  durationMs: 83000,      // when terminal
  now: "2026-10-07T13:01:23.456Z"
}
```

| Request | Returns |
|---|---|
| no parameters | The first page. |
| `?after=<next>` | The lines after the previous page. |
| `?tail=<N>` | The last N complete lines (1 to 10 000), plus `hasEarlier`/`before`. |
| `?before=<before>&limit=<N>` | Up to N lines (default 2000) immediately before the token. No `next`. |

The parameters are mutually exclusive; combining them is a `400`.

- Tokens are opaque strings (`^[A-Za-z0-9._~-]{1,128}$`). The client never parses them, so a source can use a
  record index or a byte offset.
- Every forward and tail page carries `next`, even with no lines. A page with no lines has `more: false`.
- Forward pages are capped at 2000 lines (`ConsoleOutputEndpoints.MAX_PAGE_LINES`). Every page is capped at
  8 388 608 characters; a capped tail or earlier page returns the newest lines that fit.
- A partial last line (no terminator yet) is held back until it is complete or the stream is terminal.
- A token the server no longer recognises (the log was rotated or truncated) is a `410 Gone`.
- The server owns `terminal`. `state` is only display text.

## Serving a log: `ConsoleOutputMixin`

Implement `ConsoleOutputMixin` beside your resource's superclass and resolve a log id to a source. The
resolver is where authorization lives: return empty for a log the caller may not read.

```java
@Rest(path="/builds")
public class BuildsResource extends BasicRestServlet implements ConsoleOutputMixin {

	@Override
	public Optional<ConsoleOutputSource> consoleOutputSource(String logId, RestRequest req) {
		return builds.find(logId).filter(b -> b.isVisibleTo(req)).map(Build::log);
	}
}
```

The mixin serves two endpoints under the resource:

| Endpoint | Serves |
|---|---|
| `GET /juneau-console-output/{logId}/lines` | Pages, as above. An unknown id is a `404`. |
| `GET /juneau-console-output/{logId}/download` | The whole log as JSONL, `Content-Disposition: attachment; filename="<logId>.jsonl"`. |

Log ids match `^[A-Za-z0-9_-]{1,128}$`. To use your own paths, call `ConsoleOutputEndpoints.lines(source, req,
res)` and `ConsoleOutputEndpoints.download(source, logId, res)` from your own `@RestGet` methods.

The download always uses `JsonlSerializer` and sets `Content-Type: application/jsonl` itself, so the result
does not depend on content negotiation. Each record is the line's contract map, one per JSONL line.

### Sources

`ConsoleOutputSource` is the read-side interface: `page(after)`, `tail(n)`, `before(token, limit)` and
`stream()`. Two implementations ship.

**`ConsoleOutputLog`** is an in-memory, thread-safe log for jobs your application runs itself:

```java
var log = new ConsoleOutputLog();
log.start();                                         // RUNNING
log.append(ConsoleOutputLine.info("Starting"));
log.appendAnsi(Level.INFO, "\u001b[32mok\u001b[0m"); // ANSI converted on the server
log.appendRaw(Level.INFO, processOutputReader);      // one line per terminated line
log.complete("Succeeded", Style.SUCCESS);            // terminal
```

It keeps the last `DEFAULT_MAX_LINES` (100 000) lines.

**`FileConsoleOutputSource`** reads a growing text file:

```java
var source = FileConsoleOutputSource.create(path)
	.ansi(true)                 // convert ANSI colour (the default)
	.status(job::status)        // state, style, terminal, startedAt, durationMs
	.build();
```

- It indexes line offsets as the file grows, so `tail` and `before` stay cheap on large files.
- It holds back the unterminated last line.
- If the file is truncated or replaced, old tokens get `410 Gone` and the console tells the user to reload.
- Keep **one instance per log** and reuse it across requests; the index lives in the instance.
- Resolve the path yourself from trusted data. Never build it from the log id or another request value.

### Streaming sources

The contract is polling. To feed a console from a push source (for example Server-Sent Events), mount it with
`poll: false` and call the handle's `append(lines)` from your own event handler.

## ANSI colour

`ConsoleOutputLine.fromAnsi(String)` and `fromAnsi(Level, String)` convert terminal output to fragments on the
server; the client never parses ANSI. `ConsoleOutputLine.AnsiDecoder` keeps colour state across lines, the way a
terminal does; `ConsoleOutputLog.appendAnsi` and `appendRaw` use one decoder per log.

| SGR | Result |
|---|---|
| `0` | Reset. |
| `1` / `2` / `22` | Bold on / dim on / both off. |
| `31` `91` red, `32` `92` green, `33` `93` yellow, `34` `94` blue | `style` `error`, `success`, `warn`, `accent`, so they follow the theme. |
| `35` `95` magenta, `36` `96` cyan | A fixed `color`. |
| `90` bright black | `style: muted`. |
| `30`, `37`, `97` (black and white) | Dropped; they vanish on one theme or another. |
| `38;5;n`, `38;2;r;g;b` | A fixed `#rrggbb`, unless it is nearly black or nearly white (dropped). |
| `39` | Reset the colour. |
| backgrounds, underline, blink, inverse, fonts | Ignored. |

Other escape sequences (cursor movement, erase, OSC titles and hyperlinks) are removed with their payload. A
carriage return keeps only the text after the last one, so a progress counter shows its final value. Unstyled
output stays a plain `text` line.

## Declaring the region

`ConsoleOutputDef` declares a console:

```java
var def = ConsoleOutputDef.forMixin("build-log", "/builds", buildId) // .../juneau-console-output/<id>/lines
	.tail(5000)          // initial load; "Load earlier lines" fetches more
	.rows(24)            // visible height
	.anchorPrefix("build-L")
	.title("Build output");
```

| Setter | Meaning |
|---|---|
| `linesUrl`, `downloadUrl` | Same-origin path templates (set by `forMixin`). |
| `refreshMs` | Poll interval; at least 1000 ms, default 2000. |
| `tail` | Lines to load first (1 to 10 000). Without it the console reads from the start. |
| `earlierLimit` | Lines per "Load earlier lines" click (default 2000). |
| `rows`, `compact` | Visible height; compact mode for row details. |
| `anchorPrefix` | Line anchors are `#<prefix><n>`. Must be unique on the page. |
| `showTime`, `markers` | Show timestamps; show, dim or hide marker lines. |
| `title` | The accessible name and header text. |

- `toRegion()` returns a `RegionDef` that already allows the `console-output` populator. A `RegionDef` you
  build yourself must call `allowPopulators("console-output")`.
- `{id}` in a URL template is replaced with the expanded row's id. It is only valid with
  `.type(RegionDef.TYPE_ROW_DETAIL)`; `validate()` rejects it elsewhere.
- `validate()` rejects cross-origin, scheme-relative or `..` URLs.

### In a table row detail

Put the definition's map in the catalog's detail region as `params`. The detail endpoint must still answer
`{contractVersion: '1', fields: {...}}`:

```json5
detail: {
  contractVersion: '1',
  endpoint: '/builds/rows/{id}',
  region: { id: 'output', type: 'row-detail', populate: 'console-output',
            params: { linesUrl: '/builds/juneau-console-output/{id}/lines', compact: true, rows: 12 } }
}
```

### In a FreeMarker console page

```ftl
<@card type="console-output" id="build-log" title="Build">
{ contractVersion: '1', output: { linesUrl: '/builds/juneau-console-output/42/lines', tail: 5000 } }
</@card>
```

The card is validated at render time with the same rules as `ConsoleOutputDef`; a bad URL fails the render with
a `500`. The shell mounts the card itself, with no page script. If the page did not load the views toolkit, the
shell reports E-JS-13.

## JavaScript API

`JuneauViews.consoleOutput.mount(element, options, ctx)` creates a console, starts polling, and returns a cleanup function that destroys it. `JuneauViews.consoleOutput.create(element, options)` creates a console without polling and returns a handle:

| Handle method | Does |
|---|---|
| `append(lines)` | Adds lines (an array or one object); returns how many were added. Duplicate or out-of-order `n` are skipped. |
| `prepend(lines, meta)` | Adds earlier lines above. |
| `setStatus(status)` | Updates the status header. |
| `scrollToLine(n)` | Scrolls to and highlights a line. |
| `setMarkers(mode)` | `show`, `dim` or `hide` marker lines. |
| `destroy()` | Stops polling and removes the console. |

`options` takes the same keys as `ConsoleOutputDef`. `poll: false` turns off polling.

The optional third argument is the mount context, `{signal, rowId, id, emit}`:

| Member | Meaning |
|---|---|
| `signal` | An `AbortSignal`; aborting it destroys the console. |
| `rowId` | The expanded row's id; replaces `{id}` in the URL templates. |
| `id` | Optional. The region id, used to label bus messages. |
| `emit` | Optional. A function that publishes `console-output.state` and `console-output.terminal` messages. |

The console-output card path passes an empty context.

## Security

- Line text goes into the page as text, never as HTML.
- Colours accept only the strict grammar above.
- A block `href` may be an in-page fragment (`#...`) or a same-origin path. Line data is untrusted, so a log
  can contain a working same-origin link. It still needs a click; keep state-changing operations off `GET`.
- Image `src` must be a same-origin path starting with `/`. `data:`, `blob:` and absolute URLs are rejected.
- `linesUrl` and `downloadUrl` must be same-origin paths, checked on the server and again in the browser.
- The mixin authorizes in `consoleOutputSource`. Use unguessable log ids, or check the caller there.

## Errors

The console reports problems with a `.jc-console-error` banner inside the console and a `[juneau-console-output]`
console message.

| Code | Fatal | Meaning |
|---|---|---|
| E-CO-1 | yes | Bad configuration: a missing or unsafe URL, `{id}` with no row, an invalid `anchorPrefix`, or an out-of-range number. Thrown from `mount`. |
| E-CO-2 | yes | The response `contractVersion` is not `1`. |
| E-CO-3 | no | Malformed lines were dropped. |
| E-CO-4 | for a 4xx on a forward poll (including `410`) | Fetching lines failed. Network errors and `5xx` retry with "Reconnecting…". |
| E-CO-5 | yes | An invalid continuation token, or line numbers that go backwards. |
| E-CO-6 | no | An unknown icon was ignored. |
| E-CO-7 | no | An unsafe colour, link or image was ignored. |
| E-CO-8 | no | A linked line was not found. |
| E-CO-9 | no | The anchor prefix is already used on this page; anchors are off for this console. |

## Accessibility

- The pane is `role="log"` with an accessible name, and it can be scrolled with the keyboard.
- New lines are announced politely only while the user is following the end.
- State changes are announced once, through a separate status node.
- Blocks with tooltips are focusable; tooltips show on focus and close with Escape.
- "Jump to latest" and "Load earlier lines" are buttons.
