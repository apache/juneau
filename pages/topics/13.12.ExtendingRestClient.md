title: "Extending RestClient"
slug: ExtendingRestClient
---

Subclass `RestClient` to change how every request is executed, or plug in a `RestCallHandler` for the same job without subclassing.

## When to use it

Use this when you need to intercept every call a client makes, for example to log it, sign it, or route it to a different host. For per-request changes, an interceptor or request builder is usually enough.

## Example

The following example overrides the primary run method.

```java
import java.io.*;
import org.apache.http.*;
import org.apache.http.protocol.*;
import org.apache.juneau.rest.client.classic.*;

public class MyRestClient extends RestClient {

    // Must provide this constructor!
    public MyRestClient(RestClient.Builder<?> builder) {
        super(builder);
    }

    @Override
    public HttpResponse run(HttpHost target, HttpRequest request, HttpContext context) throws IOException {
        // Perform special handling of requests, then run the default behavior.
        return super.run(target, request, context);
    }

    public static void main(String[] args) throws Exception {
        // Instantiate your client.
        try (MyRestClient client = RestClient.create().json().build(MyRestClient.class)) {
            System.out.println("Built " + client.getClass().getSimpleName());
        }
    }
}
```

The <a href="/site/apidocs/org/apache/juneau/rest/client/classic/RestRequest.html" target="_blank">RestRequest</a> and <a href="/site/apidocs/org/apache/juneau/rest/client/classic/RestResponse.html" target="_blank">RestResponse</a> objects can also be extended and integrated by overriding the
<a href="/site/apidocs/org/apache/juneau/rest/client/classic/RestClient.html#createRequest(java.net.URI,java.lang.String,boolean)" target="_blank">createRequest(URI, String, boolean)</a> and <a href="/site/apidocs/org/apache/juneau/rest/client/classic/RestClient.html#createResponse(org.apache.juneau.rest.client.RestRequest,org.apache.http.HttpResponse,org.apache.juneau.marshall.parser.Parser)" target="_blank">createResponse(RestRequest, HttpResponse, Parser)</a> methods.

## Options

| Extension point | Use it to |
|---|---|
| `run(HttpHost, HttpRequest, HttpContext)` | Wrap or replace the execution of every call |
| `createRequest(URI, String, boolean)` | Return your own `RestRequest` subclass |
| `createResponse(RestRequest, HttpResponse, Parser)` | Return your own `RestResponse` subclass |
| `RestCallHandler` | Replace call execution without subclassing the client |

## Custom call handlers

The <a href="/site/apidocs/org/apache/juneau/rest/client/classic/RestCallHandler.html" target="_blank">RestCallHandler</a> interface provides the ability to
provide custom handling of requests.

```java
import java.io.*;
import org.apache.http.*;
import org.apache.http.client.methods.*;
import org.apache.http.protocol.*;
import org.apache.juneau.rest.client.classic.*;

// Our custom call handler.
public class MyRestCallHandler implements RestCallHandler {

    private final RestClient client;

    public MyRestCallHandler(RestClient client) {
        this.client = client;
    }

    @Override
    public HttpResponse run(HttpHost target, HttpRequest request, HttpContext context) throws IOException {
        // Insert any special handling here.
        // The following is the default behavior:
        if (target == null)
            return client.execute((HttpUriRequest)request, context);
        return client.execute(target, request, context);
    }

    public static void main(String[] args) throws Exception {
        // Create a client that uses our custom handler.
        try (RestClient client = RestClient.create().json().callHandler(MyRestCallHandler.class).build()) {
            System.out.println("Built RestClient");
        }
    }
}
```

Note that there are other ways of accomplishing this such as extending the <a href="/site/apidocs/org/apache/juneau/rest/client/classic/RestClient.html" target="_blank">RestClient</a> class and overriding the <a href="/site/apidocs/org/apache/juneau/rest/client/classic/RestClient.html#run(org.apache.http.HttpHost,org.apache.http.HttpRequest,org.apache.http.protocol.HttpContext)" target="_blank">RestClient.run(HttpHost,HttpRequest,HttpContext)</a> method or by defining your own <a href="https://hc.apache.org/httpcomponents-core-4.4.x/current/httpcore/apidocs/org/apache/http/protocol/HttpRequestExecutor.html" target="_blank">HttpRequestExecutor</a>.
Using this interface is often simpler though.
