The `HtmlFlavorRest` class in the petstore console (the Html subtab at `/console/dev/flavors/html`) shows how <a href="/site/apidocs/org/apache/juneau/bean/html5/package-summary.html" target="_blank">HTML5 beans</a> can be used to generate arbitrary HTML on REST endpoints.

## table

The `fragment()` method, served at `/console/dev/flavors/html/fragment`, shows an example of
rendering an HTML table, built from live petstore data.

```java
@RestGet(path="/fragment", serializers=HtmlSerializer.class)
public Table fragment() {
    var rows = new ArrayList<Object>();
    rows.add(tr(th("Name"), th("Species"), th("Price"), th("Status")));
    for (var r : FlavorPets.rows(store()))
        rows.add(tr(td(r.get("name")), td(r.get("species")), td(r.get("price")), td(r.get("status"))));
    return table(rows.toArray()).class_("petstore-flavor").attr("data-flavor", "html");
}
```

This is the fragment in a browser:

![The fragment endpoint rendered as an HTML table of pets with name, species, price and status columns](/topics/HtmlBeans.table.png)

The endpoint is limited to `HtmlSerializer`, so it has no JSON representation; the beans themselves serialize to
JSON like any other bean when an endpoint allows it.

## div

The following method shows an example of
rendering a div tag with mixed content. (The petstore console has no per-pet card endpoint; this illustrates the bean API directly.)

```java
@RestGet("/card")
public Div aCard() {
    return div(
        p(b("Rex")),
        p("Species: Dog"),
        p("Price: $100"),
        p("Status: AVAILABLE")
    );
}
```

## form

The following method shows an example of
rendering an HTML form using the <a href="/site/apidocs/org/apache/juneau/bean/html5/Form.html" target="_blank">Form</a> HTML5 bean. (The petstore samples don't currently host a form-bean demo resource; this illustrates the bean API directly.)

```java
@RestGet
@HtmlDocConfig(
    aside={
        "",
        "	Example of serialized org.apache.juneau.bean.html5.Form bean.",
        ""
    }
)
public Form aForm() {
    return form().action("/submit").method("POST")
        .children(
            "Position (1-10000): ", input("number").name("pos").value(1), br(),
            "Limit (1-10000): ", input("number").name("limit").value(100), br(),
            button("submit", "Submit"), button("reset", "Reset")
        );
}
```
