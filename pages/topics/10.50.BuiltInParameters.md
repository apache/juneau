---
title: "Built-in Parameters"
slug: BuiltInParameters
---

The following URL parameters have special meaning and can be passed in through the URL of the request:

| GET Parameter | Description |
|---------------|-------------|
| `&plainText=true` | Response will always be `Content-Type: text/plain` and the returned text will be human-readable (<a href="/site/apidocs/org/apache/juneau/marshall/serializer/WriterSerializer.Builder.html#useWhitespace()" target="_blank">WriterSerializer.Builder.useWhitespace()</a> enabled).<br />Useful for debugging. |
| `&method=X` | Overload the HTTP method as a GET parameter (e.g "POST").<br />Must be enabled via <a href="/site/apidocs/org/apache/juneau/rest/server/Rest.html#allowedMethodParams()" target="_blank">@Rest(allowedMethodParams)</a> setting. |
| `&Header-Name=headerValue` | Specify a header value as a GET parameter (e.g. `&Accept=text/json`).<br />Must be enabled via <a href="/site/apidocs/org/apache/juneau/rest/server/Rest.html#allowedHeaderParams()" target="_blank">@Rest(allowedHeaderParams)</a> setting. |
| `&content=X` | Pass in the HTTP body content on PUT and POST methods as a UON-encoded GET parameter (e.g. `?content=(name='John%20Smith',age=45)`).<br />Honored on `PUT`/`POST` only. Can be disabled via <a href="/site/apidocs/org/apache/juneau/rest/server/Rest.html#disableContentParam()" target="_blank">@Rest(disableContentParam)</a> setting. |
| `&x-response-headers=X` | Pass-through headers to the response.<br />Must be a UON-encoded map of key-value pairs. |
| `&juneauSerializerOptions=X` | Override serializer session options for this request.<br />Must be a UON-encoded map; keys must be in the <a href="/site/apidocs/org/apache/juneau/rest/server/Rest.html#allowedSerializerOptions()" target="_blank">@Rest(allowedSerializerOptions)</a> allowlist or the request fails with `400 Bad Request`. |
| `&juneauParserOptions=X` | Override parser session options for this request.<br />Must be a UON-encoded map; keys must be in the <a href="/site/apidocs/org/apache/juneau/rest/server/Rest.html#allowedParserOptions()" target="_blank">@Rest(allowedParserOptions)</a> allowlist or the request fails with `400 Bad Request`. |

:::note
Earlier releases documented `&debug=true` and `&noTrace=true` URL parameters. These no longer exist.
Request debugging is now driven by the JUL logger level (see
[Logging / Debugging](/docs/topics/RestServerLoggingAndDebugging)), and the `/echo` endpoint must be
enabled explicitly via `EchoMixin`.
:::
