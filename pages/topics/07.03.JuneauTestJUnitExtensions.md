The `juneau-test` module bundles a small JUnit 5 extension (formerly the standalone `juneau-junit5` module) for **test-time bean injection** — swapping production beans with test doubles inside a Juneau `BeanStore` for the duration of a JUnit 5 test, without modifying production code and without proxying. It is the Juneau-flavored answer to Spring's `@TestConfiguration` / `@MockBean`.

The extension lives in the <a href="/site/apidocs/org/apache/juneau/test/junit/package-summary.html" target="_blank">org.apache.juneau.test.junit</a> package and centers on three types:

- <a href="/site/apidocs/org/apache/juneau/test/junit/JuneauBeanStoreExtension.html" target="_blank">JuneauBeanStoreExtension</a> — the JUnit 5 `Extension`, registered via `@ExtendWith` or `@RegisterExtension`.
- <a href="/site/apidocs/org/apache/juneau/test/junit/TestBean.html" target="_blank">TestBean</a> — the field/method annotation that declares an override.
- <a href="/site/apidocs/org/apache/juneau/test/junit/TestBeanStore.html" target="_blank">TestBeanStore</a> — the overlay bean store, resolvable as a test-method parameter.

## Quick start

```java
import static org.junit.jupiter.api.Assertions.*;

import org.apache.juneau.test.junit.*;
import org.junit.jupiter.api.*;
import org.junit.jupiter.api.extension.*;

@ExtendWith(JuneauBeanStoreExtension.class)
class MyServiceTest {

    @TestBean
    ExternalApi mockApi = () -> "test-double";

    @Test
    void resolvesTheTestDouble(TestBeanStore store) {
        assertSame(mockApi, store.getBean(ExternalApi.class).orElseThrow());
    }

    interface ExternalApi { String describe(); }
}
```

## Two wiring modes

- **Mode INJECT** (default) — construction-time wiring. The system-under-test is built *after* the overlay, which is threaded into the builder's `overridingBeanStore(...)` setter. Universal: every bean type is eligible for replacement, including ones the framework would otherwise pin into a per-op memoizer at boot.
- **Mode OVERLAY** — push/pop overlays on a long-lived SUT (typically a `Microservice` booted once in `@BeforeAll`), applied and removed per test via `@TestBean(mode = Mode.OVERLAY)`.

The `overridingBeanStore(BeanStore)` setter is available on every builder implementing `BeanStoreOverridable<B>`: `MockRestClient.Builder`, `Microservice.Builder`, `SerializerSet.Builder`, `ParserSet.Builder`, and `EncoderSet.Builder`.

## Reference

### @TestBean attributes

| Attribute | Default | Description |
|---|---|---|
| `name` | `""` | Bean qualifier name; empty means unnamed. |
| `type` | `Object.class` | Bean type to register under.  When left as `Object.class` the field's declared type (or the method's return type) is used. |
| `scope` | `Scope.METHOD` | `Scope.METHOD` (fresh overlay per test method) or `Scope.CLASS` (shared overlay for the whole class; only valid on `static` members). |
| `mode` | `Mode.INJECT` | `Mode.INJECT` or `Mode.OVERLAY` (see above).  Mixing both modes within one scope throws `IllegalStateException`. |

`@TestBean` may be placed on fields or on methods (the method is invoked to supply the bean).  Method-scope overlays are
stacked on top of the class-scope overlay, so a method-scope bean takes precedence over a class-scope bean of the same type.

### Registering the extension

```java
// Declarative
@ExtendWith(JuneauBeanStoreExtension.class)
class MyTest { ... }

// Programmatic, when you need the extension instance
class MyTest {
    @RegisterExtension
    static JuneauBeanStoreExtension ext = JuneauBeanStoreExtension.create();
}
```

<a href="/site/apidocs/org/apache/juneau/test/junit/JuneauBeanStoreExtension.html" target="_blank">JuneauBeanStoreExtension</a>
implements `BeforeAllCallback`, `AfterAllCallback`, `BeforeEachCallback`, `AfterEachCallback` and `ParameterResolver`.

| Method | Description |
|---|---|
| `create()` | Static factory for `@RegisterExtension`. |
| `attach(WritableBeanStore)` / `detach()` | Attach the overlay to (or detach it from) a long-lived store, as used by Mode OVERLAY. |
| `getAttachedStore()` | The attached store, as an `Optional`. |
| `getStore()` | The active overlay for the current test method or class. |
| `getStore(Scope)` | The overlay for the given scope, as an `Optional<TestBeanStore>`. |
| `discoverOverrides(Object)` | Static; scans a test instance (and its hierarchy) for `@TestBean` members and returns the overrides. |

### TestBeanStore

<a href="/site/apidocs/org/apache/juneau/test/junit/TestBeanStore.html" target="_blank">TestBeanStore</a> extends `BasicBeanStore`
and has no JUnit dependency.  It can be created with `new TestBeanStore()` or `new TestBeanStore(BeanStore parent)`
and can be declared as a test-method parameter to receive the current overlay.

| Method | Description |
|---|---|
| `override(Class<T>, T)` | Register an unnamed override. |
| `override(Class<T>, T, String)` | Register a named override. |
| `override(Class<T>, Supplier<T>)` | Register a lazily supplied override. |
| `override(Class<T>, Supplier<T>, String)` | Register a lazily supplied, named override. |
