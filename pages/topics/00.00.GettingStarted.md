New to Juneau? Work through these four short pages in order. Each builds on the previous one and takes
a few minutes.

1. [Install Juneau](/docs/topics/GettingStartedInstall): add the BOM and the modules you need.
2. [Your first serializer](/docs/topics/GettingStartedSerializer): turn a bean into JSON and back.
3. [Your first REST app](/docs/topics/GettingStartedRestApp): expose a bean over HTTP.
4. [Your first client](/docs/topics/GettingStartedClient): call it with the REST client.

## Prefer to start from a working project?

The [Starter Projects](/docs/topics/StarterProjects) are clone-and-go "Hello World" apps for Jetty,
Spring Boot, and Tomcat. The [Petstore](/docs/topics/JuneauPetstore) is a fuller showcase, and the
[Examples](/docs/topics/JuneauExamples) cover marshalling and MCP.

## Coming from Juneau 9?

Read the [V10 Migration Guide](/docs/topics/V10MigrationGuide) first. It has the module, package, and
API rename tables. If you use the REST client, also see [Choosing a REST Client](/docs/topics/ChoosingARestClient).
