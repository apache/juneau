Juneau supports converting arbitrary POJOs to and from the **Protobuf Text Format** using native serializers and parsers implemented without any external dependencies. This is the human-readable text format (not the binary wire format) used for protobuf configuration files, debugging, and interop with tools like `protoc --decode`. The <a href="/site/apidocs/org/apache/juneau/marshall/prototext/PrototextSerializer.html" target="_blank">PrototextSerializer</a> converts POJOs directly to Protobuf Text Format, and the <a href="/site/apidocs/org/apache/juneau/marshall/prototext/PrototextParser.html" target="_blank">PrototextParser</a> creates POJOs directly from protobuf text without intermediate DOM objects.

**No `.proto` schema files are required**—Java bean metadata provides the type information.

<DependencyInfo artifact="juneau-marshall" mavenOnly note="Protobuf Text Format support is included in juneau-marshall." />

## Quick Start

```java
// Serialize a bean to Protobuf Text Format
Person p = new Person("Alice", 30);
String proto = Prototext.of(p);
```

Produces:

```
name: "Alice"
age: 30
```

## Parsing

```java
// Parse Protobuf Text Format into a bean
Person parsed = Prototext.to(proto, Person.class);

// Parse into a Map or JsonMap
JsonMap map = Prototext.to(proto, JsonMap.class);
```

## Serialization

```java
// Use the default serializer
String proto = PrototextSerializer.DEFAULT.write(someObject);

// Use the marshaller for convenience
String proto = Prototext.of(someObject);
```

## Bean-to-Protobuf Mapping

The conversion follows the <a href="https://protobuf.dev/reference/protobuf/textformat-spec" target="_blank">Protobuf Text Format specification</a>:

- **Maps and beans** → Message fields with brace delimiters or colon syntax
- **Collections and arrays of simple values** → List syntax `[v1, v2, ...]`
- **Collections of beans** → Repeated field names
- **Strings** → Quoted strings with C-style escaping
- **Numbers** → Numeric literals (decimal, hex, octal)
- **Booleans** → `true` / `false`
- **Enums** → Unquoted identifiers
- **Date/time and Duration** → ISO 8601 strings
- **null** → Omitted (no null representation in protobuf text format)

## Pre-configured instances

| Instance | Description |
|---|---|
| `PrototextSerializer.DEFAULT` | Default settings. |
| `PrototextSerializer.DEFAULT_READABLE` | Same, with `useWhitespace()` enabled for more readable output. |
| `PrototextParser.DEFAULT` | Default parser. |

## Serializer settings

Configured through `PrototextSerializer.create()`
(see <a href="/site/apidocs/org/apache/juneau/marshall/prototext/PrototextSerializer.Builder.html" target="_blank">PrototextSerializer.Builder</a>),
in addition to the settings inherited from `WriterSerializer` (`useWhitespace()`, `addBeanTypes()`, `keepNullProperties()`, swaps, etc.).

| Builder method | Default | Description |
|---|---|---|
| `useListSyntaxForBeans(boolean)` | `false` | Write collections of beans using list syntax (`[{...}, {...}]`) instead of repeated field names. |
| `useColonForMessages(boolean)` | `false` | Write message-valued fields as `field: { ... }` instead of `field { ... }`. |

```java
PrototextSerializer s = PrototextSerializer.create()
    .useListSyntaxForBeans(true)
    .useColonForMessages(true)
    .build();
String proto = s.write(someBean);
```

## Parser settings

`PrototextParser` has no format-specific settings beyond those inherited from `ReaderParser`
(see <a href="/site/apidocs/org/apache/juneau/marshall/prototext/PrototextParser.Builder.html" target="_blank">PrototextParser.Builder</a>).
Comments (`# ...`) in the input are ignored.

## Annotations

The <a href="/site/apidocs/org/apache/juneau/marshall/prototext/Prototext.html" target="_blank">@Prototext</a> annotation
(on a class, field or method) has a `comment` attribute.  When specified, a `# text` comment line is written before the field:

```java
public class Person {
    @Prototext(comment="Years since birth")
    public int age = 30;

    public String name = "Alice";
}
```

Produces:

```
# Years since birth
age: 30
name: "Alice"
```

<a href="/site/apidocs/org/apache/juneau/marshall/prototext/PrototextConfig.html" target="_blank">@PrototextConfig</a>
applies serializer settings on a REST class or method (see [Context Annotations](/docs/topics/ContextAnnotations)):

| Attribute | Description |
|---|---|
| `useListSyntaxForBeans` | `"true"` / `"false"` (default).  Maps to `useListSyntaxForBeans(boolean)`. |
| `useColonForMessages` | `"true"` / `"false"` (default).  Maps to `useColonForMessages(boolean)`. |
| `rank` | Ordering relative to other config annotations. |

```java
@Rest
@PrototextConfig(useColonForMessages="true")
public class MyResource extends BasicRestServlet { ... }
```

## Media Types

- **Produces**: `text/protobuf`
- **Accept**: `text/protobuf`, `text/x-protobuf`

## REST Integration

```java
// Use BasicPrototextConfig for Protobuf-only REST resources
@Rest
public class MyResource extends RestServlet implements BasicPrototextConfig { ... }

// Protobuf is also included in BasicUniversalConfig
@Rest
public class MyResource extends RestServlet implements BasicUniversalConfig { ... }
```
