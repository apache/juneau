The [org.apache.juneau.commons.lang](/site/apidocs/org/apache/juneau/commons/lang/package-summary.html) package provides language utilities including value wrappers, version management, string formatting, state enums, and other common language constructs.

## Key Classes

### <java-class><a href="/site/apidocs/org/apache/juneau/commons/lang/Holder.html" target="_blank">Holder</a></java-class>
A generic mutable value wrapper.

```java
// Basic usage
Holder<String> name = Holder.of("John");
name.set("Jane");
String result = name.get();  // Returns "Jane"

// Use in lambda (effectively final variable)
Holder<String> result = Holder.empty();
list.forEach(x -> {
    if (x.matches(criteria)) {
        result.set(x);
    }
});

// With default values
Holder<String> optional = Holder.empty();
String value = optional.orElse("default");  // Returns "default"

// Mapping values
Holder<Integer> number = Holder.of(5);
Holder<String> text = number.map(Object::toString);  // Holder of "5"

// With listener for change notification
Holder<String> monitored = Holder.of("initial")
    .listener(newValue -> log("Value changed to: " + newValue));
monitored.set("updated");  // Triggers listener
```

### Specialized Holder Classes

### <java-class><a href="/site/apidocs/org/apache/juneau/commons/lang/IntegerHolder.html" target="_blank">IntegerHolder</a></java-class>
Mutable integer with additional convenience methods.

```java
IntegerHolder counter = IntegerHolder.of(0);
counter.increment();  // 1
counter.decrement();  // 0
int value = counter.getAndIncrement();  // Returns 0, then sets to 1
```

### <java-class><a href="/site/apidocs/org/apache/juneau/commons/lang/LongHolder.html" target="_blank">LongHolder</a></java-class>
Mutable long with additional convenience methods.

```java
LongHolder counter = LongHolder.of(0L);
counter.increment();  // 1L
counter.decrement();  // 0L
long value = counter.getAndIncrement();  // Returns 0L, then sets to 1L
```

### <java-class><a href="/site/apidocs/org/apache/juneau/commons/lang/BooleanHolder.html" target="_blank">BooleanHolder</a></java-class>
Nullable boolean with convenience methods.

```java
BooleanHolder flag = BooleanHolder.of(true);
flag.isTrue();  // true
flag.isNotTrue();  // false

BooleanHolder nullable = BooleanHolder.empty();
nullable.isTrue();  // false (null is not true)
nullable.isNotTrue();  // true (null is not true)
```

### <java-class><a href="/site/apidocs/org/apache/juneau/commons/lang/Flag.html" target="_blank">Flag</a></java-class>
Non-nullable boolean flag (true/false only, no null state).

```java
Flag flag = Flag.of(true);
flag.isTrue();  // true
flag.isFalse();  // false
flag.toggle();  // Switches to false
```

### <java-class><a href="/site/apidocs/org/apache/juneau/commons/lang/StringHolder.html" target="_blank">StringHolder</a></java-class>
Mutable string with convenience methods for equality testing.

```java
StringHolder name = StringHolder.of("John");

// Check equality
if (name.is("John")) {
    System.out.println("Name is John");
}

// Check multiple values
if (name.isAny("John", "Jane", "Bob")) {
    System.out.println("Name found");
}
```

### <java-class><a href="/site/apidocs/org/apache/juneau/commons/lang/StringFormat.html" target="_blank">StringFormat</a></java-class>
Cacheable printf-style string formatter (backed by `String.format` semantics).

```java
// Printf-style formatting
StringFormat fmt = StringFormat.ofPrintf("Hello %s, you have %d items");
String result = fmt.format("John", 5);
// Returns: "Hello John, you have 5 items"

// Printf with explicit argument indices
StringFormat fmt2 = StringFormat.ofPrintf("%1$s loves %2$s, and %1$s also loves %3$s");
String result2 = fmt2.format("Alice", "Bob", "Charlie");
// Returns: "Alice loves Bob, and Alice also loves Charlie"

// A one-shot helper is also available for non-cached use
String result3 = StringFormat.formatPrintf("%s has %d items", "Alice", 10);
// Returns: "Alice has 10 items"
```

:::note
`StringFormat` is **printf-only** — MessageFormat-style `{0}` placeholders are **not** recognized and render
literally (`{` and `'` are treated as ordinary text). This applies consistently across the terse helpers too:
`Shorts.f()` / `Shorts.fs()` and `StringUtils.format(...)` are also printf-only. If you need MessageFormat-style
`{0}` / `''`-quoting, use `Shorts.mf()` / `Shorts.mfs()` / `StringUtils.mformat(...)` (backed directly by
`java.text.MessageFormat`) instead — there is no single class that mixes both grammars in one pattern. See the
[10.0.0 release notes](/docs/release-notes/10.0.0) for migration details.
:::

#### Which String-Formatting Entry Point Should I Use?

`StringFormat`, `StringUtils.format(...)`/`mformat(...)`, and `Shorts.f()`/`mf()` all coexist deliberately —
they're three different call-site shapes over the same two underlying grammars (printf and MessageFormat),
not three competing implementations. Use this table to pick the right one:

| Use... | When... |
|---|---|
| `Shorts.f(pattern, args)` / `Shorts.mf(pattern, args)` | You want the terse, one-off, static-import-friendly call — most call sites (logging, exception messages, assertions). `f` = printf-style, `mf` = MessageFormat-style. |
| `Shorts.fs(pattern, args)` / `Shorts.mfs(pattern, args)` | Same as above, but the formatting cost should be deferred — e.g. a logging API that takes a `Supplier<String>` and only calls it when the log level is enabled. |
| `StringUtils.format(pattern, args)` / `mformat(pattern, args)` | You're already in `juneau-commons` code that avoids the `Shorts` static-import convention, or you want the fully-qualified name for clarity in a public API signature. `Shorts.f`/`mf` are thin aliases over these two methods — behavior is identical either way. |
| `StringFormat.ofPrintf(pattern)` | The **same pattern is reused repeatedly** (e.g. in a loop, or as a `static final` field) and you want to pay the pattern-parsing cost once via the built-in cache, rather than re-parsing on every call. Printf-style only — there is no `StringFormat` MessageFormat counterpart. |

:::note
`StringFormat` is the odd one out shape-wise (a stateful/cacheable class, not a static one-shot method) — reach
for it only when reuse/caching matters. For everything else, `Shorts.f`/`mf`/`fs`/`mfs` are the recommended
entry point; `StringUtils.format`/`mformat` are the methods they delegate to and remain public for callers
that prefer explicit, non-abbreviated names.
:::

### <java-class><a href="/site/apidocs/org/apache/juneau/commons/lang/HashCode.html" target="_blank">HashCode</a></java-class>
Utility class for generating integer hash codes.

```java
int hashCode = HashCode.create()
    .add("foobar")
    .add(myObject)
    .add(123)
    .get();
```

### <java-class><a href="/site/apidocs/org/apache/juneau/commons/lang/Version.html" target="_blank">Version</a></java-class>
Version management utility.

```java
Version version = Version.of("1.2.3");
version.getMajor();       // Optional.of(1)
version.getMinor();       // Optional.of(2)
version.getMaintenance();  // Optional.of(3)

int major = version.getMajor().orElse(0);  // 1

// Compare versions
Version v1 = Version.of("1.2.3");
Version v2 = Version.of("1.2.4");
int comparison = v1.compareTo(v2);  // -1 (v1 < v2)
```

### <java-class><a href="/site/apidocs/org/apache/juneau/commons/lang/VersionRange.html" target="_blank">VersionRange</a></java-class>
Version range utility for checking if a version string falls within an OSGi-style range.

```java
VersionRange range = VersionRange.of("[1.0.0,2.0.0)");
boolean inRange = range.matches("1.5.0");  // true
```

### <java-enum><a href="/site/apidocs/org/apache/juneau/commons/lang/StateEnum.html" target="_blank">StateEnum</a></java-enum>
Enumeration of state machine states for use in parsing operations.

```java
import static org.apache.juneau.commons.lang.StateEnum.*;

// Use in state machine
var state = S1;
if (state == S1) {
    // Handle state S1
} else if (state == S2) {
    // Handle state S2
}
```

### <java-enum><a href="/site/apidocs/org/apache/juneau/commons/lang/TriState.html" target="_blank">TriState</a></java-enum>
Three-state enum (TRUE, FALSE, UNKNOWN).

```java
TriState state = TriState.TRUE;
state.isTrue();  // true
state.isFalse();  // false
state.isUnknown();  // false

TriState unknown = TriState.UNKNOWN;
unknown.isTrue();  // false
unknown.isFalse();  // false
unknown.isUnknown();  // true
```

### <java-class><a href="/site/apidocs/org/apache/juneau/commons/lang/AsciiSet.html" target="_blank">AsciiSet</a></java-class> and <java-class><a href="/site/apidocs/org/apache/juneau/commons/lang/AsciiMap.html" target="_blank">AsciiMap</a></java-class>
Utilities for working with ASCII character sets and maps.

```java
AsciiSet asciiSet = AsciiSet.of("abc");
boolean contains = asciiSet.contains('a');  // true

AsciiMap<String> asciiMap = AsciiMap.of();
asciiMap.put('a', "alpha");
String value = asciiMap.get('a');  // "alpha"
```

## Common Patterns

### Mutable Values in Lambdas

```java
// Use Holder to create effectively final mutable variables
Holder<String> result = Holder.empty();
list.stream()
    .filter(x -> x.matches(pattern))
    .forEach(x -> result.set(x));

String found = result.orElse("not found");
```

### Version Checking

```java
String current = "1.2.3";
VersionRange supported = VersionRange.of("[1.0.0,2.0.0)");

if (supported.matches(current)) {
    // Version is supported
}
```

### State Machine

```java
import static org.apache.juneau.commons.lang.StateEnum.*;

StateEnum state = S1;
while (state != null) {
    switch (state) {
        case S1:
            // Process S1
            state = S2;
            break;
        case S2:
            // Process S2
            state = S3;
            break;
        // ...
    }
}
```
