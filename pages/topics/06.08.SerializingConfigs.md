The following methods are used for serializing `Config` objects back into their text form:

Both methods are thread safe.

## Writing to a Writer

`writeTo(Writer)` appends the current contents of the config to the specified writer and returns that same writer.
The writer is not closed by this method.

:::tip Example
```java
Config config = Config.create("MyConfig.cfg").build();

// Dump the config to a string.
StringWriter sw = new StringWriter();
config.writeTo(sw);
String contents = sw.toString();

// Or write it straight to a file.
try (Writer w = new FileWriter("MyConfig-copy.cfg")) {
    config.writeTo(w);
}
```
:::

`toString()` returns the same text that `writeTo(Writer)` produces.

The output reflects the in-memory state of the config, including changes that have been made but not yet
committed (see [Config Stores](/docs/topics/ConfigStores) for where committed changes go).

## Output format

Serialization goes through the config's <a href="/site/apidocs/org/apache/juneau/config/format/ConfigFormat.html" target="_blank">ConfigFormat</a>.
The format is auto-detected from the config name (a name ending in `.yml` or `.yaml` selects YAML, anything else selects INI),
or set explicitly with `Config.Builder.ini()`, `Config.Builder.yaml()` or `Config.Builder.format(ConfigFormat)`.
See [INI Config Format](/docs/topics/IniConfigFormat) and [YAML Config Files](/docs/topics/YamlConfigFiles).

:::tip Example
```java
// A config named with a .yaml extension serializes as YAML.
Config yamlConfig = Config.create("MyConfig.yaml").build();
String yamlText = yamlConfig.toString();

// Force INI output regardless of the name.
Config iniConfig = Config.create("MyConfig.txt").ini().build();
String iniText = iniConfig.toString();
```
:::
