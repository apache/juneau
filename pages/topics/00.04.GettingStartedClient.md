The REST client calls the service from the [previous page](/docs/topics/GettingStartedRestApp) and parses
the response into the same `Pet` bean.

```java
import org.apache.juneau.marshall.json5.*;
import org.apache.juneau.rest.client.*;

RestClient client = RestClient.builder()
    .rootUrl("http://localhost:10000")
    .serializer(Json5Serializer.create().build())
    .parser(Json5Parser.create().build())
    .build();

try (var resp = client.get("/pets/{id}").pathData("id", 1).run()) {
    resp.assertOk();
    Pet pet = resp.body().as(Pet.class);
}

client.close();
```

Always close the response (it holds the connection) and close the client at shutdown.

Juneau ships two REST client stacks. The example above uses the next-generation `juneau-rest-client`,
which runs on the JDK `HttpClient` with no extra dependencies. See
[Choosing a REST Client](/docs/topics/ChoosingARestClient) if you need the Apache HttpClient-based
classic client.
