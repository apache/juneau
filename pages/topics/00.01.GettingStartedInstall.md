Juneau requires **Java 17+**. All modules are published to Maven Central under the group id
`org.apache.juneau`.

## Import the BOM

Import `juneau-bom` once, then leave the version off every Juneau dependency. See
[Dependency Management](/docs/topics/DependencyManagement) for details.

```xml
<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>org.apache.juneau</groupId>
            <artifactId>juneau-bom</artifactId>
            <version>${juneau.version}</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>
```

## Pick your modules

| You want to... | Add |
|---|---|
| Serialize and parse beans (JSON, XML, HTML, YAML, and more) | `juneau-marshall` |
| Build a REST API | `juneau-rest-server` (plus one of the [starters](/docs/topics/StarterProjects) or a [microservice bundle](/docs/topics/DependencyManagement) to run it) |
| Call REST APIs | `juneau-rest-client` (see [Choosing a REST Client](/docs/topics/ChoosingARestClient)) |
| Test REST code without a network | `juneau-rest-mock` |

```xml
<dependencies>
    <dependency>
        <groupId>org.apache.juneau</groupId>
        <artifactId>juneau-marshall</artifactId>
    </dependency>
</dependencies>
```

`juneau-marshall` needs no third-party dependencies. The full list of modules, with their
prerequisites, is in the [Ecosystem Overview](/docs/topics/JuneauEcosystemOverview).
