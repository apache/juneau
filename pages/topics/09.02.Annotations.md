The <a href="/site/apidocs/org/apache/juneau/http/package-summary.html" target="_blank">org.apache.juneau.http</a> package contains annotations for defining both
server and client side APIs.

The server-side APIs also use it for producing auto-generated Swagger documentation through the REST API itself.

These annotations are used in a variety of places in the server and client side REST interfaces, especially for remote
proxies.
They are provided by the `juneau-rest-common` module, so they are available to both server and client code without depending on either.

All of them have runtime retention.

## HTTP part annotations

These bind a method parameter (or bean property or type) to one part of an HTTP request.
All of the following are `@Inherited`. `@Header`, `@Query`, `@FormData`, `@Path` and `@PathRemainder` may be applied to parameters, methods, types and fields; the others are as noted.

| Annotation | Purpose | Notable attributes |
|---|---|---|
| <a href="/site/apidocs/org/apache/juneau/http/Content.html" target="_blank">@Content</a> | The request body. Targets: parameter, method, type. | `def`, `description`, `summary`, `schema` |
| <a href="/site/apidocs/org/apache/juneau/http/Header.html" target="_blank">@Header</a> | A request header. | `name`, `value` (alias for `name`), `def`, `description`, `summary`, `schema` |
| <a href="/site/apidocs/org/apache/juneau/http/Query.html" target="_blank">@Query</a> | A query parameter. | `name`, `value`, `def`, `description`, `summary`, `schema` |
| <a href="/site/apidocs/org/apache/juneau/http/FormData.html" target="_blank">@FormData</a> | A form-data entry. | `name`, `value`, `def`, `description`, `summary`, `schema` |
| <a href="/site/apidocs/org/apache/juneau/http/Path.html" target="_blank">@Path</a> | A path variable. | `name`, `value`, `def`, `description`, `summary`, `schema` |
| <a href="/site/apidocs/org/apache/juneau/http/PathRemainder.html" target="_blank">@PathRemainder</a> | The remainder of the path after the pattern match. | `def`, `description`, `schema` |
| <a href="/site/apidocs/org/apache/juneau/http/HasQuery.html" target="_blank">@HasQuery</a> | Whether the request has the named query parameter. Parameter only. | `name`, `value`, `description` |
| <a href="/site/apidocs/org/apache/juneau/http/HasFormData.html" target="_blank">@HasFormData</a> | Whether the request has the named form-data parameter. Parameter only. | `name`, `value`, `description` |

## Request and response bean annotations

| Annotation | Purpose | Notable attributes |
|---|---|---|
| <a href="/site/apidocs/org/apache/juneau/http/Request.html" target="_blank">@Request</a> | Marks an interface or parameter as a request bean exposing several HTTP parts through getters. Targets: parameter, type, method. | `description` |
| <a href="/site/apidocs/org/apache/juneau/http/Response.html" target="_blank">@Response</a> | Marks a type, method or parameter as a response bean. | `description`, `summary`, `examples`, `headers`, `schema` |
| <a href="/site/apidocs/org/apache/juneau/http/StatusCode.html" target="_blank">@StatusCode</a> | Denotes an HTTP response status code. | `value` (int array), `description` |

## Client-only (remote proxy) annotations

| Annotation | Purpose | Notable attributes |
|---|---|---|
| <a href="/site/apidocs/org/apache/juneau/http/Part.html" target="_blank">@Part</a> | A `multipart/form-data` part on a remote-proxy method parameter. Parameter only. | `name`, `value`, `fileName`, `contentType` |
| <a href="/site/apidocs/org/apache/juneau/http/Url.html" target="_blank">@Url</a> | A remote-proxy parameter supplying the entire request URL. Parameter only. | |

## Swagger metadata annotations

These are not applied to parameters. They are used as nested values of `@Swagger` (`contact`, `license` and `tags`), which is supplied through `@Rest(swagger=...)`, to populate the generated Swagger document.

| Annotation | Purpose | Attributes |
|---|---|---|
| <a href="/site/apidocs/org/apache/juneau/http/Contact.html" target="_blank">@Contact</a> | Contact information for the API. | `name`, `url`, `email`, `description` |
| <a href="/site/apidocs/org/apache/juneau/http/License.html" target="_blank">@License</a> | License information for the API. | `name`, `url`, `description` |
| <a href="/site/apidocs/org/apache/juneau/http/Tag.html" target="_blank">@Tag</a> | Metadata for a single Swagger tag. | `name`, `description`, `externalDocs` |
