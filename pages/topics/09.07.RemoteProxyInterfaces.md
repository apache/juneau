The <a href="/site/apidocs/org/apache/juneau/http/remote/package-summary.html" target="_blank">org.apache.juneau.http.remote</a> package contains the annotations used for defining
client-side remote proxies.

## When to use it

Use a remote proxy when you want to call a REST API through a plain Java interface instead of building each request by hand.

See the guide: [Call an existing REST API with a typed proxy](/docs/guides/TypedProxyClient)

## Example

```java
import org.apache.juneau.http.*;
import org.apache.juneau.http.remote.*;

@Remote(path="/petstore")
public interface PetStore {

    @RemoteGet("/pets/{petId}")
    String getPet(@Path("petId") int petId);

    @RemotePost("/pets")
    String addPet(@Content String pet, @Query("debug") boolean debug);
}
```
