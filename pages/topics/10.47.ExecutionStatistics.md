---
title: "REST method execution statistics"
slug: ExecutionStatistics
---

<a href="/site/apidocs/org/apache/juneau/rest/server/Rest.html" target="_blank">Rest</a>-annotated classes get automated timing and error
statistic information for all <a href="/site/apidocs/org/apache/juneau/rest/server/RestOp.html" target="_blank">@RestOp</a> and lifecycle-event annotated methods on the class.
If you extend from <a href="/site/apidocs/org/apache/juneau/rest/server/servlet/BasicRestServlet.html" target="_blank">BasicRestServlet</a> or <a href="/site/apidocs/org/apache/juneau/rest/server/servlet/BasicRestResource.html" target="_blank">BasicRestResource</a>, then the statistics are made available through the REST interface via the <a href="/site/apidocs/org/apache/juneau/rest/server/ops/StatsMixin.html" target="_blank">StatsMixin</a> op-mixin's following method:

```java
@RestGet(
    path="/stats",
    summary="Timing statistics",
    description="Timing statistics for method invocations on this resource."
)
@Override /* StatsMixin */
public RestContextStats getStats(RestRequest req) {
    return req.getContext().getStats();
}
```

Rendered in a browser, the method table looks like this. The rows are the methods of the petstore's about resource
(`/console/about/stats`); each shows its run count, timing and error counts:

![The per-method statistics table of the petstore about resource](/topics/ExecutionStatistics.1.png)

The default REST configuration provides a link to the stats in the navlinks section of the page:

![The about resource's navlinks: UP, API and STATS](/topics/ExecutionStatistics.2.png)

When a method throws, the `thrownStore` column links to the stored exceptions. Each one carries a hash that is also
written to the log file, which gives a quick way of locating the exception in the logs.
