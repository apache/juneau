Juneau supports converting arbitrary POJOs to and from BSON (Binary JSON) using native serializers and parsers. BSON is the binary serialization format used by MongoDB, extending JSON with typed integers (int32/int64), native datetime, decimal128, and binary data. It uses little-endian byte order and length-prefixed documents.

The <a href="/site/apidocs/org/apache/juneau/marshall/bson/BsonSerializer.html" target="_blank">BsonSerializer</a> converts POJOs directly to BSON format, and the <a href="/site/apidocs/org/apache/juneau/marshall/bson/BsonParser.html" target="_blank">BsonParser</a> creates POJOs directly from BSON.

<DependencyInfo artifact="juneau-marshall" mavenOnly note="BSON support is included in juneau-marshall." />

## Quick Start

```java
// A simple bean
public class Person {
    public String name;
    public int age;
    public Person() {}
    public Person(String name, int age) { this.name = name; this.age = age; }
}

// Serialize a bean to BSON
Person alice = new Person("Alice", 30);
byte[] bson = Bson.of(alice);

// Parse BSON into a bean
Person parsed = Bson.to(bson, Person.class);
```

## Parsing

```java
// Parse BSON into a bean
Person p = Bson.to(bson, Person.class);

// Parse into a map
JsonMap map = Bson.to(bson, JsonMap.class);

// Parse into a typed map
Map<String, Object> m = Bson.to(bson, Map.class, String.class, Object.class);

// Parse a list (root must be document; use wrapped {"value": [...]} for standalone arrays)
List<Person> people = Bson.to(bson, List.class, Person.class);
```

## Serialization

```java
// Use the default serializer
byte[] bson = BsonSerializer.DEFAULT.write(someObject);

// Use the marshaller for convenience
byte[] bson = Bson.of(someObject);

// Custom serializer: write dates as ISO 8601 strings instead of BSON datetime
BsonSerializer s = BsonSerializer.create().writeDatesAsDatetime(false).build();
byte[] bson = s.write(someObject);
```

## Java-to-BSON Type Mapping

| Java Type | BSON Type | Notes |
|-----------|-----------|-------|
| Bean, Map | Document (0x03) | Nested structures |
| Collection, array | Array (0x04) | Document with "0", "1", ... keys |
| String, Enum | String (0x02) | |
| int, short, byte | Int32 (0x10) | 4 bytes little-endian |
| long | Int64 (0x12) | 8 bytes little-endian |
| float, double | Double (0x01) | IEEE 754 |
| Date, Calendar, Instant | Datetime (0x09) | When writeDatesAsDatetime=true |
| Duration | String | ISO 8601 duration |
| byte[] | Binary (0x05) | Subtype 0x00 |
| BigDecimal, BigInteger | Decimal128 (0x13) | IEEE 754-2008 |
| null | Null (0x0A) | |

Local `java.time` types with no instant (`LocalDate`, `LocalDateTime`, `LocalTime`, `Year`, etc.) are always written as ISO 8601 strings.
BSON datetime has millisecond resolution, so sub-millisecond precision of `Instant`, `OffsetDateTime` and `ZonedDateTime` is truncated
when `writeDatesAsDatetime` is `true`; use `writeDatesAsDatetime(false)` for lossless ISO 8601 output.
`BigDecimal` / `BigInteger` values outside the Decimal128 range (34 significant digits, exponent -6176..6111) cannot be represented
and fail with a `SerializeException`.

## Pre-configured instances

| Instance | Description |
|---|---|
| `BsonSerializer.DEFAULT` / `BsonParser.DEFAULT` | Default settings; raw BSON bytes. |
| `BsonSerializer.DEFAULT_SPACED_HEX` / `BsonParser.DEFAULT_SPACED_HEX` | `binaryFormat(SPACED_HEX)`. |
| `BsonSerializer.DEFAULT_BASE64` / `BsonParser.DEFAULT_BASE64` | `binaryFormat(BASE64)`. |

The binary format setting only affects the stream-to-string conveniences (such as `writeToString`); the serializer
always emits native BSON bytes from `write(...)`.

## Serializer settings

Configured through `BsonSerializer.create()`
(see <a href="/site/apidocs/org/apache/juneau/marshall/bson/BsonSerializer.Builder.html" target="_blank">BsonSerializer.Builder</a>).

| Builder method | Default | Description |
|---|---|---|
| `addBeanTypesBson(boolean)` | `false` | Add `_type` properties to beans whose type cannot be inferred through reflection. |
| `writeDatesAsDatetime(boolean)` | `true` | Write `Date` / `Calendar` / `Instant` as BSON datetime (0x09); when `false`, write ISO 8601 strings. |
| `nullKeyString(String)` | `"<NULL>"` | Field name used for `null` map keys (BSON field names cannot be null). |
| `binaryFormat(BinaryFormat)` | `NOT_SET` | Text rendering (`SPACED_HEX`, `HEX`, `BASE64`, `BASE64_URL`) used by string conveniences. |

The defaults can also be set with the `BsonSerializer.addBeanTypesBson`, `BsonSerializer.nullKeyString` and
`BsonSerializer.writeDatesAsDatetime` environment settings.

## Parser settings

Configured through `BsonParser.create()`
(see <a href="/site/apidocs/org/apache/juneau/marshall/bson/BsonParser.Builder.html" target="_blank">BsonParser.Builder</a>).

| Builder method | Default | Description |
|---|---|---|
| `nullKeyString(String)` | `"<NULL>"` | A field with this name is stored with a `null` key in the target map.  Must match the serializer value. |
| `trimStrings(boolean)` | `false` | Trim whitespace from parsed string values (inherited from `Parser`). |
| `binaryFormat(BinaryFormat)` | `NOT_SET` | Binary text-format hint (`SPACED_HEX`, `HEX`, `BASE64`, `BASE64_URL`); see `BinaryFormat`. |

```java
BsonSerializer s = BsonSerializer.create()
    .writeDatesAsDatetime(false)
    .nullKeyString("~null~")
    .build();
BsonParser p = BsonParser.create().nullKeyString("~null~").build();

byte[] bson = s.write(someMap);
Map<?,?> m = p.read(bson, Map.class);
```

## Media Types

- **Produces**: `application/bson`
- **Accepts**: `application/bson`

## REST Integration

```java
// BSON support is included via BasicUniversalConfig (there is no dedicated BSON-only config interface).
@Rest
public class MyResource extends RestServlet implements BasicUniversalConfig { ... }

// RestClient with BSON
RestClient client = RestClient.create().uri("http://localhost:8080").bson().build();
byte[] response = client.get("/api/data").bson().run().body();
```

## Limitations

- **Root must be a document**: BSON requires a top-level document. Standalone scalars, collections, and arrays are wrapped as `{value: x}`.
- **Map keys must be strings**: Non-string keys use `toString()`. Null keys use a configurable placeholder.
- **ObjectId is read-only**: BSON ObjectId (0x07) is parsed as a 24-character hex string; Juneau does not generate ObjectIds.
- **Deprecated types skipped**: Undefined, DBPointer, Symbol, JS with Scope are silently skipped during parsing.
- **MongoDB-internal types unsupported**: JavaScript, Timestamp, MinKey, MaxKey are not supported.

## Annotations

<a href="/site/apidocs/org/apache/juneau/marshall/bson/BsonConfig.html" target="_blank">@BsonConfig</a> sets serializer/parser properties on a REST class or method
(see [Context Annotations](/docs/topics/ContextAnnotations)). Attributes are strings:

| Attribute | Description |
|---|---|
| `addBeanTypes` | Add `_type` properties to beans whose type can't be inferred through reflection (default `false`). |
| `writeDatesAsDatetime` | Write `Date`/`Calendar`/`Instant` as the BSON datetime type (0x09); if `false`, write ISO-8601 strings. |
| `maxLength` | Maximum wire-declared length (bytes) for strings, binary payloads and document/array size prefixes when parsing; guards against malicious size prefixes. |
| `rank` | Ordering relative to other config annotations. |

```java
@Rest
@BsonConfig(writeDatesAsDatetime="true", maxLength="1048576")
public class MyResource extends BasicRestServlet { ... }
```

<a href="/site/apidocs/org/apache/juneau/marshall/bson/Bson.html" target="_blank">@Bson</a> is a class/method/field marker (its only attribute is `description`),
and <a href="/site/apidocs/org/apache/juneau/marshall/bson/BsonApply.html" target="_blank">@BsonApply</a> applies it to other
classes/members via `on()`/`onClass()` (see [Dynamically Applied Annotations](/docs/topics/DynamicallyAppliedAnnotations)).
