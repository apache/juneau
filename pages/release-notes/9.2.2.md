# Release 9.2.2

**Date:** 11/05/2026

Juneau 9.2.2 is a bug-fix release for 9.2.1.

## Bug fixes

### juneau-marshall

- `ClassMeta` is now added to the class-meta cache only after it is fully constructed. Previously a concurrent `getClassMeta()` call, or a `Map`/`Collection` class meta copied from a half-built one, could see a null `swaps` and fail serialization with `Cannot invoke "java.util.function.Supplier.get()" because "this.swaps" is null`.
