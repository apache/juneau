# Release 10.1.0

**Status:** In development. The release date is not set yet.

Juneau 10.1.0 follows [10.0.0](/docs/release-notes/10.0.0). The notes below list only changes already on the main branch since 10.0.0; more will be added as the release takes shape.

## juneau-terminal

- The tmux engine behind the watch-run and tmux-pane scripts (`tmux-pane.sh`, `watch-run.sh`, `tmux-toolbar.sh`) is ported to Python. The three `.sh` files remain as thin shims at the same paths.
- Split mode gains a `--keep never|fail|always` option (also `JUNEAU_TERMINAL_KEEP`) that controls when a run's panes stay open after it ends.
