# Release 9.2.3

**Date:** 11/17/2026

Juneau 9.2.3 is a maintenance release for 9.2.2 that fixes security bugs. It adds no new features. Upgrading is recommended.

## Security fixes

This release fixes a number of security bugs and hardens input validation and error handling in the REST server, REST client, parsers and `juneau-sc`.

## Upgrade notes

- **Server error responses.** The `Thrown` response header and exception detail are sent only for `BasicHttpException`, `@Response`-annotated exceptions and RRPC calls, or when `@Rest(renderResponseStackTraces="true")` is set. A client that relies on typed rethrow of other server exceptions needs that setting on the server.
- **`juneau-sc`.** The `/configs` endpoint now requires an API key. Set `Security/apiKey` in `juneau-server-config.cfg` and send it as `Authorization: Bearer <key>` or `X-Api-Key: <key>`.

## Other changes

- Jetty updated to 12.1.15 and JGit to 7.8.1.
- `BasicJettyServerFactory` no longer fails to parse Jetty XML configuration on JDK 28. It sets the system property `org.eclipse.jetty.xml.XmlParser.Validating` to `false` when it is not already set.
